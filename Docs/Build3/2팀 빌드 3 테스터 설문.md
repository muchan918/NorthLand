- 팀명: 2팀 (유유아)
- 대상 빌드: Build 3 (Windows)
- 소요 시간: 플레이 20분 + 설문 5~10분

## 작성 방법

이 파일을 복사해서 `2팀 빌드 3 테스터 설문_이름.md` 로 저장한 뒤 작성해 주세요.
해당하는 항목의 `[ ]` 를 `[x]` 로 바꾸고, **이유** 칸에 한 줄씩 적어주시면 됩니다. 이유는 비워도 됩니다.

## 플레이 안내

- zip 압축을 풀고 exe 실행 → 타이틀 화면에서 "게임 시작"
- 카메라: WASD 또는 우클릭 드래그로 이동, 휠로 줌
- 목표: 낮에 자원을 모으고 방어를 준비 → 밤에 몰려오는 몬스터로부터 본진을 지킨다
- 가능하면 **7웨이브까지** 플레이해 주세요. 중간에 게임오버되면 다시 시작해도 됩니다.
