## 빌드 목표

이번 빌드의 방향은 **"빌드에 깊이 더하기"** 다. 빌드 2에서 낮 → 밤 → 웨이브 클리어 → 보상 → 다음 낮으로 이어지는 핵심 루프가 자동으로 도는 것을 확인했으므로, 이번에는 그 루프 안에 성장 축을 만드는 데 집중했다.

- **전투 공간의 성장 축** — 타워 합성. 같은 타워를 계속 깔지 않고, 설치한 타워를 재료로 상위 타워를 만든다.
- **경영 공간의 성장 축** — 건물 클릭 기능. 본진 · 마법 연구소 · 연금술사의 집에 각각 고유 기능을 붙여 마나석 소비처를 만든다.
- **콘텐츠 확장** — 위 두 축의 선택지를 채우는 타워 · 몬스터 추가. 중간보스와 최종 보스로 웨이브의 끝을 만든다.
- **편의성 · 버그 수정** — 빌드 2 테스트에서 접수된 개선 요청과 버그 처리.

## 포함된 기능 / 변경 사항

### 타워 합성 (신규)

전투 공간의 성장 축. 같은 타워를 계속 깔지 않고, 이미 설치한 타워를 재료로 상위 타워를 만든다.

- 설치된 타워를 **Shift + 클릭으로 여러 개 선택**한다. 1개만 선택하면 기존 타워 정보 패널이 뜨고, 2개 이상이면 합성 패널로 바뀐다.
- 합성 패널은 위에 선택한 재료 목록, 아래에 만들 수 있는 결과 타워 후보 버튼을 띄운다. 레시피 조건을 만족하는 후보만 버튼이 활성화된다.
- 매칭은 **포함 방식**이다. 선택한 타워가 레시피 요구량보다 많아도 성립하고, 소모는 요구한 개수만큼만 일어난다. 남는 타워는 그대로 남는다.
- 후보 버튼을 누르면 일반 타워 배치와 똑같이 고스트가 마우스를 따라오고, 배치를 확정하는 순간 **추가 비용이 차감되고 재료 타워가 사라지면서** 결과 타워가 생성된다.
- 합성은 **낮(배치 페이즈) 전용**이다. 밤으로 넘어가거나 씬이 바뀌면 선택이 초기화된다.

### 본진 패널 (신규)

- 본진을 클릭하면 전용 패널이 열린다.
- 주민 수 증가 버튼을 통해 **주민 수도 늘어난다** — 생산 라인에 배치할 수 있는 인력이 증가한다.
- 업그레이드하면 **다른 건물들의 최대 레벨 상한이 올라간다.** 즉 본진이 경영 성장의 중앙 게이트 역할을 한다 — 본진을 올리지 않으면 생산 건물도 일정 레벨에서 막힌다.
- 업그레이드에는 자원이 소모되며, 자원이 부족하면 진행되지 않는다.

### 마법 연구소 (신규)

- 클릭하면 스킬 업그레이드 패널이 열린다. 마나석을 소모해 레벨을 올린다.
- 레벨이 오르면 **플레이어 스킬의 기본 능력치가 상승한다**(감전 · 버프 양쪽 모두).
- 웨이브 클리어 보상으로 얻는 스킬 특수효과와는 **별개 트랙**이다. 보상은 효과를 추가하고, 연구소는 기본 수치를 올린다.

### 연금술사의 집 (신규)

- 클릭하면 교환 상점 패널이 열린다.
- **마나석을 다른 자원으로 교환**한다. 기본 자원 3종(나무 · 철 · 식량)과 특수 자원 4종(금 · 루비 · 사파이어 · 다이아)을 한 패널에서 전부 교환할 수 있다.
- 본진을 업그레이드하면 **교환 효율이 좋아진다** — 같은 마나석으로 더 많은 자원을 받는다.

### 버프 타일 (신규)

- 전투맵이 생성될 때 **버프 타일이 무작위 위치에 무작위 수치로** 배치된다.
- 그 타일 위에 타워를 설치하면 지속적으로 사거리 증가 버프를 받는다.
- 버프 수치에 비례해 타일이 융기해서, 얼마나 좋은 타일인지 눈으로 구분된다.

### 타워 2종 추가 — 상태이상

기존 6종에 슬로우 · 스턴 계열이 추가돼 총 8종이 됐다.

- **소다 타워** — 단일 대상 공격 타워. 명중할 때마다 대상을 **0.7초 기절**시킨다. 연사로 이동을 계속 끊는 역할.
- **초코 타워** — 주변 40 반경에 지속 디버프 오라를 뿌린다. 범위 안 몬스터의 **이동속도를 20% 감소**시키고, 1초 간격으로 갱신되며 벗어나면 2초 후 해제된다.

### 보스 · 중간보스 (신규)

몬스터 AI를 **Behaviour Tree**로 새로 구성했다. 보스와 중간보스 모두 BT 기반 위에서 동작하며, 정해진 웨이포인트 경로를 벗어나지 않고 경로 위에서 패턴을 쓴다.

- **중간보스** — 이동 중 스스로 속도를 올리고 내리며 접근하고, HP가 30% 아래로 떨어지면 한 번만 회복한다.
- **최종 보스(Tank)** — 상황에 따라 패턴을 골라 쓴다.
  - **본진 돌진** — 본진까지 거리가 일정 이하로 좁혀지면 가속해 돌진하고, 도달하면 본진에 충돌 피해를 준다. 판당 한 번만 발동한다.
  - **방어 태세** — 뒤따라오는 잡몹이 일정 수 이상이면 크롤 속도로 느려지는 대신 받는 피해가 줄어든다.
  - **마력 봉인** — 앞쪽에 타워와 잡몹이 함께 몰려 있으면 범위 내 공격 타워의 공격 속도를 떨어뜨린다. 완전히 멈추지는 않으며, 버프 · 디버프 오라 타워는 봉인되지 않는다.
  - **지속 소환(기본 행동)** — 살아 있는 동안 일정 간격으로 잡몹을 계속 불러낸다. 보스를 죽이지 않으면 유입이 멎지 않는다.

방어 태세와 마력 봉인이 모두 주변 잡몹 수를 발동 조건으로 삼고, 잡몹은 지속 소환으로 계속 유입되므로 "잡몹부터 정리할지 보스부터 집중할지"를 고르게 된다.

### 공중 유닛 몬스터 (신규)

- 지상 몬스터와 달리 웨이포인트 경로를 따르지 않고, **지정된 지점으로 곡선을 그리며 이동**한다.

### 게임 속도 조절 (신규)

- x1 / x2 / x4 배속을 지원한다. 밤 페이즈 진행이 늘어질 때 빠르게 넘길 수 있다.
- 게임 시간 전체를 한 곳에서 제어하므로 UI · 연출도 함께 맞춰 빨라진다.

### 설정 패널 (신규)

- **ESC로 언제든 토글**된다. 언어 변경 / 타이틀로 나가기 / 게임 종료를 제공한다.
- 언어를 바꾸면 열려 있는 패널의 텍스트까지 즉시 갱신된다.
- 타이틀 씬의 버튼들도 실제 기능에 연결됐다(게임 종료 포함).

### 개선 — 상호작용 표시 규칙 통일

무엇을 가리키고 있고 무엇을 고른 상태인지 색으로 구분한다.

- 마우스를 올리면 **노란색** 아웃라인
- 선택하면 **초록색**(합성 그룹 선택도 포함)
- 합성 후보 버튼에 마우스를 올리면, 그 레시피에 실제로 쓰이는 **재료 타워만 핑크색**으로 표시된다 — 여러 개 선택했을 때 어느 게 소모될지 미리 알 수 있다

### 개선 — 사거리 · 타워 패널

- 타워 설치 중에 뜨는 사거리 원이 잘 보이게 개선됐다.
- **설치된 타워를 클릭해도 사거리가 표시된다.** 배치 후에 커버 범위를 확인할 수 있다.
- 타워 패널 버튼에 마우스를 올리면 **코스트와 주요 스탯이 툴팁**으로 뜬다. 설치해 보기 전에 뭘 짓는지 알 수 있다.

### 개선 — 경영 페이즈 진행 방식

- 기존의 "영토 확장 → 주민 배치 → 낮 종료"를 순서대로 강제하던 게이팅을 **해제**했다. 하고 싶은 것만 하고 넘어갈 수 있다.
- 대신 낮을 끝낼 때 **확인 팝업**을 띄워 실수로 밤에 넘어가는 것을 막는다.
- 주민 배치가 날짜가 바뀌어도 유지된다 — 매일 다시 배치할 필요가 없다.

### 개선 — UI 레이어

- 패널이 겹치는 순서를 표준화했다. 미니맵 · 보상 패널 · 게임 결과 패널이 서로를 가리지 않는다.
- 위에 뜬 패널이 **아래쪽 입력을 차단**한다. 보상 선택 창이 떠 있는데 뒤의 미니맵이 눌리는 문제가 없어졌다.

### 개선 — 전투맵 생성

- 침식이 본진 쪽 시작 구간까지 갉아먹어 경로가 어색해지던 문제를 고쳤다. 본진 인접 구간은 침식되지 않는다.

### 버그 수정

- 밤에도 건물이 건설되던 문제 (건설은 낮 전용으로 게이팅)
- 웨이브가 끝났는데 스킬 효과가 남아 다음 웨이브로 이어지던 문제
- 투사체가 몬스터 발밑을 조준해 명중 지점이 어색했던 문제 (대상별 피격 지점을 따로 잡도록 분리)
- 영토 확장 시 특정 높이 이상의 노드에서 선택 표시(소용돌이)가 보이지 않던 문제
- 시간 정지 중 미니맵으로 이동이 안 되던 문제
- 게임 종료 후 입력 · 시간 상태가 정리되지 않던 문제

- 경영 공간 건물
  - 생산 건물(나무꾼의 집 · 광산 · 농장): 클릭 → 정보 패널 → 업그레이드

- 주민 배치: 경영 패널 생산 라인에서 `+`/`-`로 배정
- 타워 배치: 하단 타워 버튼 클릭 → 고스트 프리팹이 마우스를 따라다니고 배치 가능한 타일에만 설치
- 타워 합성: 배치된 타워를 shift를 통해 복수 선택 후 합성 타워 버튼 클릭하여 배치
- 밤 전환: 우측 위 "다음" 버튼 클릭 → 전투 공간 맵 생성 + 웨이브 SO 기준 몬스터 스폰
- 밤 페이즈 스킬: 하단 스킬 UI 선택 → 전투 타일 클릭으로 시전
- 웨이브 클리어: 스폰된 몬스터 전멸 시 클리어 → 마나석 지급 + 보상 선택 창(보상 존재 시) → 다음 낮
- 테스트용: BalanceTest 패널의 치트 버튼으로 자원/웨이브 상태 강제 조작
