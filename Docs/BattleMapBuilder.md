# 타일 기반 맵 설계 가이드

큰 그리드와 블록(7×7 타일 단위)으로 맵을 구성할 때 적용하는 규칙을 정리한 문서. 새 맵을 만들거나 기존 맵의 규칙을 검토할 때 참고 용도로 쓴다.

> 이 문서의 규칙은 스케치를 기준으로 정리한 초안이다. 규칙이 바뀌거나 실제 맵 제작 중 예외가 생기면 이 문서도 함께 갱신해서, 문서와 실제 맵이 어긋나지 않게 유지한다.

## 1. 기본 단위

| 용어 | 정의 |
| --- | --- |
| 블록 | 큰 그리드의 칸 1개. 7×7 타일로 구성된다 |
| 구역 | 큰 그리드를 위 / 오른쪽 / 왼쪽 / 중앙 4개로 나눈 영역 |
| 포인트 | 구역 안에서 무작위로 지정되는, 반드시 도달해야 하는 블록 |

## 2. 구역 및 포인트 규칙

- 각 구역에는 포인트 후보 블록이 4개 이상 존재한다.
- 맵을 생성할 때마다 각 구역의 포인트 후보 중 하나가 무작위로 그 구역의 포인트로 지정되며, 4개 구역 모두에 포인트가 지정되어야 한다.
- 한 블록이 특정 구역의 포인트로 지정되면, 그 블록은 다른 구역의 포인트 지정 대상에서 제외된다.
- 구역이 지정되는 순서는 무작위이며, 이미 포인트가 지정된 구역은 다음 순서에서 제외한 채 반복한다.
  - ex) 첫 번째로 "위" 구역에 포인트가 지정됐다면, 다음은 왼쪽 / 오른쪽 / 중앙 중 하나에 포인트 지정.
  - 두 번째로 "왼쪽" 구역에 포인트가 지정됐다면, 다음은 남은 "오른쪽" / "중앙" 중 하나에 포인트 지정.
  - 이렇게 4개 구역 모두에 포인트가 지정될 때까지 반복한다.
- 지정된 4개 포인트 블록 사이의 최소 이동 경로는 30블록 이상(1블록 = 7×7 타일)이 되도록 조절한다.

## 3. 표기 규칙

| 표시 | 의미 |
| --- | --- |
| 파란 격자선 | 블록 경계 (블록 1칸 = 7×7 타일) |
| 주황 점 | 필수 연결점 — 인접 블록으로 진입하려면 이 지점을 반드시 통과 |

## 4. 신규 맵 만들 때 체크리스트

- [ ] 큰 그리드 크기 결정 (가로 × 세로 블록 수)
- [ ] 위 / 오른쪽 / 왼쪽 / 중앙 4개 구역과, 구역별 포인트 후보 블록(4개 이상) 배치
- [ ] 구역별 포인트를 무작위로 지정 (지정 순서 무작위, 구역당 중복 지정 금지)
- [ ] 지정된 4개 포인트 사이 최소 이동 경로가 30블록 이상인지 확인 — 미달 시 포인트 재배치
- [ ] 블록 경계에 필수 연결점(주황 점) 배치 — 연결점 없는 경계는 통과 불가로 확정
