> ⚠️ **현재 전 항목이 ⬜(미확인)이다.** 아래 체크리스트는 이번 빌드에 들어간 변경을 근거로 작성한 **테스트 대장**이며, 실제 플레이 판정은 테스트 후 채운다.

## 테스트 시나리오

판정이 테스터마다 엇갈리지 않도록, 아래 경로는 공통으로 밟은 뒤 체크한다.

> 타이틀에서 **시드를 적어 두고** 게임 시작 → 영토 1개 확보 → 주민이 돌아다니는지 확인 → 주민 배치 → 생산 건물 업그레이드 → 낮 종료 → 타워 배치 → **드래그로 복수 선택 → 합성 → 되돌리기(Undo)** → 다시 합성해 확정 → 웨이브 1 클리어 → 마나석으로 연금술사 교환 → 본진 업그레이드 → 마법 연구소 업그레이드(감전 이펙트 변화 확인) → 4웨이브 중간보스 → **여기서 타이틀로 나갔다가 "이어하기"** → 7웨이브 보스까지 완주

추가로 각 1회씩:
- **적어 둔 시드를 타이틀에 입력해 새 판 시작** — 첫 판과 같은 맵 · 같은 영토가 나오는지
- 중도 게임오버(본진 HP 0) 후 타이틀 → 이어하기 버튼이 사라졌는지
- 배속 x4로 한 웨이브 진행
- 신규 타워 6종을 각 1기 이상 배치해 교전 확인

## 기능별 테스트 결과

### Run 마스터 시드 (신규)

- ⬜ 타이틀에서 시드를 입력하지 않으면 매 판 다른 맵 · 영토가 나온다
- ⬜ 같은 시드를 입력하면 전투맵 지형 · 경로가 동일하게 재현된다
- ⬜ 같은 시드를 입력하면 영토 그래프 배치와 영지 종류가 동일하게 재현된다
- ⬜ 잘못된 시드 입력(빈 값 · 문자 · 범위 초과)이 거부되고 게임이 깨지지 않는다
- ⬜ 전투맵이 중복 생성되지 않는다(부트스트랩 순서로 통합됨)
- ⬜ 버프 타일의 위치 · 수치가 매 판 달라진다 ※ 빌드 3 ❌ 항목 — 시드 연결 대상에 없어 재발 가능

### Run 저장 및 이어하기 (신규)

- ⬜ 낮이 시작될 때 자동 저장이 일어난다
- ⬜ 세이브가 있을 때만 타이틀에 "이어하기" 버튼이 뜬다
- ⬜ 이어하기로 진입하면 저장된 일차 · 웨이브 번호에서 재개된다
- ⬜ 자원 보유량이 그대로 복원된다
- ⬜ 확보한 영토가 그대로 복원된다
- ⬜ 건설된 건물과 각 레벨이 그대로 복원된다
- ⬜ 설치된 타워의 종류와 위치가 그대로 복원된다
- ⬜ 본진 체력이 그대로 복원된다
- ⬜ 보상으로 얻은 스킬 특수효과와 중첩 레벨이 그대로 복원된다
- ⬜ 마법 연구소 스킬 레벨이 그대로 복원된다
- ⬜ 전투맵 공개 범위가 저장된 웨이브까지 복원된다
- ⬜ 복원된 타워 위치에 다시 배치가 되지 않는다(타일 점유 복원)
- ⬜ 이어하기 직후 중복 저장이 일어나지 않는다
- ⬜ 이어하기 후 복원된 자원으로 건설 · 업그레이드가 정상 동작한다
- ⬜ 승리 또는 패배로 런이 끝나면 세이브가 삭제되고 이어하기 버튼이 사라진다
- ⬜ 이어하기 후 남은 웨이브를 끝까지 완주할 수 있다

### 타워 6종 추가 (신규)

- ⬜ 화염지대 타워를 타워 패널에서 직접 배치할 수 있다
- ⬜ 화염지대 범위 안의 몬스터에게 화상이 들어간다
- ⬜ 화염궁수 타워가 명중 시 화상을 건다
- ⬜ 소이캐논 타워가 스플래시 + 화상을 함께 넣는다
- ⬜ 산탄 타워가 펠릿 3발을 부채꼴로 발사한다
- ⬜ 산탄 펠릿이 고속에서도 몬스터를 관통해 지나치지 않는다(터널링 없음)
- ⬜ 부메랑 타워의 투사체가 나갔다 돌아오며 관통한다
- ⬜ 부메랑이 같은 적을 한 구간에서 두 번 때리지 않는다
- ⬜ 멀티인페르노 타워가 여러 대상을 동시에 빔으로 잠근다
- ⬜ 멀티인페르노의 빔이 타워 상단에서 나간다(바닥에서 나오지 않는다)
- ⬜ 캐논 타워가 포물선으로 발사되고 정상 명중한다
- ⬜ 캐논 타워가 공중 유닛에게 데미지를 넣는다 ※ 빌드 3 ❌ 항목

### 타워 획득 경로 재편 (개선)

- ⬜ 타워 패널에 직접배치 7종만 표시된다
- ⬜ 합성 전용 타워는 패널에 나타나지 않는다
- ⬜ 합성 전용 타워를 실제로 합성으로 얻을 수 있다(6종 전부 도달 가능)
- ⬜ 아처 3기를 선택하면 개틀링 · 산탄 버튼이 함께 뜨고 둘 다 만들 수 있다
- ⬜ 합성 결과 타워가 재료의 효과(화상 등)를 계승한다
- ❌ 번개사슬 타워를 얻을 수 있다 ※ 레시피 · 프리팹 미배선 — 획득 불가 상태

### 드래그 사각형 그룹 선택 (신규)

- ⬜ 빈 곳에서 좌클릭 드래그하면 선택 사각형이 그려진다
- ⬜ 사각형 안에 들어온 타워가 전부 합성 선택된다
- ⬜ 짧게 클릭하면(임계 미만) 기존 단일 선택으로 동작한다
- ⬜ Shift + 클릭 복수 선택이 그대로 동작한다
- ⬜ 드래그 선택 후 합성 패널이 정상적으로 뜬다
- ⬜ 빈 곳 클릭 · Esc로 선택이 해제된다
- ⬜ 밤으로 전환되면 선택이 초기화된다
- ⬜ 타워 배치 · 스킬 조준 중에는 드래그 선택이 시작되지 않는다
- ⬜ 미니맵 · UI 위에서 시작한 드래그가 선택을 만들지 않는다
- ⬜ 우클릭 카메라 이동과 충돌하지 않는다

### 타워 배치 · 합성 되돌리기(Undo) (신규)

- ⬜ 타워를 배치한 뒤 Undo로 되돌릴 수 있다
- ⬜ 되돌리면 지불한 자원이 환원된다
- ⬜ 되돌린 타일에 다시 배치할 수 있다
- ⬜ 합성을 확정한 뒤 Undo로 되돌리면 결과 타워가 사라지고 재료 타워가 복원된다
- ⬜ 여러 번 배치했을 때 최근 순서(LIFO)대로 되돌아간다
- ⬜ 되돌릴 것이 없으면 Undo 버튼이 동작하지 않는다
- ⬜ 밤으로 넘어가면 그 이전 낮의 조작은 되돌릴 수 없다
- ⬜ 타이틀로 나갔다가 다시 시작했을 때 이전 판의 히스토리가 남아 있지 않다

### 타워 합성 — 커맨드 패턴 (개선)

- ⬜ 합성 후보 버튼을 누르는 순간 재료 타워가 사라진다
- ⬜ 배치를 취소하면 재료 타워가 원래 자리로 복원된다
- ⬜ 복원된 재료가 원래 점유했던 타일을 되찾는다
- ⬜ 자원이 부족하면 합성 버튼이 동작하지 않고 재료도 소모되지 않는다
- ⬜ 요구량보다 많이 선택해도 필요한 개수만 소모된다

### 주민 (신규)

- ⬜ 낮에 주민이 마을을 돌아다닌다
- ⬜ 주민이 지형(계단 · 다리)을 통해 마을 · 대지 · 섬을 오간다
- ⬜ 주민이 건물 내부로 들어가지 않는다
- ⬜ 주민이 걷다가 가끔 잠깐 멈춘다(휴식)
- ⬜ 주민끼리 마주치면 가끔 대화가 열린다(항상은 아니다)
- ⬜ 대화 중 서로를 보고 화자가 번갈아 바뀐다
- ⬜ 진행 중인 대화에 세 번째 주민이 합류하고 원형으로 재배치된다
- ⬜ 지나가는 주민이 대화 중인 무리를 밀어내지 않는다
- ⬜ 주변에 아무도 없을 때 주민이 춤을 춘다 ※ 정본 씬 밀도에서 안 나올 수 있음(WL-153)
- ⬜ 밤이 되면 주민이 가장 가까운 문으로 뛰어 들어간다
- ⬜ 아침이 되면 주민이 다시 나온다
- ⬜ 주민에 마우스를 올리면 노란 아웃라인이 뜬다
- ⬜ 주민을 클릭 · 드래그로 선택하면 초록 아웃라인이 뜬다
- ⬜ 생산 라인에 배정하면 화면의 주민 수가 그만큼 줄어든다
- ⬜ 유휴 주민이 0명이면 더 선택되지 않는다
- ⬜ 밤 전환 후 아침에 초록 아웃라인이 남아 있지 않다

### 스킬 (개선)

- ⬜ 보상 카드에 현재 레벨 → 획득 후 레벨과 수치 변화가 표시된다
- ⬜ 만렙(3레벨)에 도달한 특수효과가 보상 후보에서 제외된다
- ⬜ 상한에 도달하면 레벨이 더 오르지 않는다
- ⬜ 카드 표기가 ko / en / ja 모두 정상 표시된다
- ⬜ 마법 연구소 레벨을 올리면 감전 스킬의 착탄 이펙트가 바뀐다
- ⬜ 착탄 이펙트 크기가 인디케이터 반경과 어긋나지 않는다
- ⬜ 스킬 인디케이터가 원기둥 형태로 표시된다
- ⬜ 타일 높낮이가 다른 지형에서도 인디케이터가 정상 표시된다
- ⬜ 인디케이터로 보이는 범위와 실제 적중 범위가 일치한다
- ⬜ 연구소 레벨이 낮을 때(Lv0, 반경 3)도 스킬이 몬스터에 적중한다 ※ 부양 높이 문제(WL-068)
- ⬜ 스킬 범위에 몬스터가 많이 몰려도 일부가 누락되지 않는다 ※ 버퍼 16 고정(WL-157)

### 연출 (신규)

- ⬜ 타워를 배치하면 입자가 수렴하며 타워가 등장한다
- ⬜ 합성 시 재료가 흰 실루엣으로 수축 → 폭발 → 입자로 부유한다
- ⬜ 배치를 확정하면 입자가 결과 타워로 수렴한다
- ⬜ 배치를 취소하면 입자가 되돌아가 재료가 재조립된다
- ⬜ 전투맵 타일이 불규칙하게 올라오며 등장한다
- ⬜ 이어하기 시 타일 등장 연출이 생략되고 즉시 최종 위치에 배치된다
- ⬜ 연출 중 씬 전환 · 취소가 일어나도 스케일 0인 타워가 남지 않는다
- ⬜ 배속 · 일시정지 상태에서 연출이 멈추거나 깨지지 않는다
- ⬜ 줌 전 구간에서 입자 크기가 적절하게 보인다

### 전역 비주얼 룩 (신규)

- ⬜ 본진(경영 공간)이 툰 셰이딩으로 렌더된다
- ⬜ 그림자 경계가 하드 컷으로 끊긴다
- ⬜ 변환된 머티리얼에 텍스처 · 색 · 노멀 · 이미시브가 누락 없이 옮겨졌다
- ⬜ 반투명 · 알파 클립 오브젝트가 깨지지 않는다
- ⬜ 선택 · 호버 아웃라인이 툰 셰이딩과 겹쳐 이상해지지 않는다
- ⬜ 낮 → 밤 조명 전환이 툰 머티리얼에서도 정상 동작한다

### 합성 족보 패널 (신규, 테스트용)

- ⬜ 패널에 레시피 목록이 전부 표시된다
- ⬜ 각 레시피의 재료와 결과가 실제 합성 동작과 일치한다

### 웨이브 진행 (개선)

- ⬜ 웨이브가 리스트 등록 순서대로 진행된다
- ⬜ 최종 웨이브 클리어로 게임이 정상 종료된다
- ⬜ 전투맵 공개 범위가 웨이브 진행에 맞게 늘어난다 ※ 분모가 별도 값(씬 30)이라 어긋날 수 있음(WL-150)

### 마우스 상호작용 정리 (개선)

- ⬜ 타워 배치 중(고스트 표시 중) 설정 버튼을 누르면 고스트가 사라진다
- ⬜ 타워 배치 중 "다음"(낮 종료) 버튼을 누르면 고스트가 사라진다
- ⬜ 설정 패널이 열려 있는 동안 뒤쪽 배치 · 선택 입력이 차단된다

### 회귀 확인 (기존 기능)

- ⬜ TitleScene → GameScene 전환, 게임 종료
- ⬜ 초기 자원 지급 → 타워 배치 비용 차감 → 자원 부족 시 버튼 비활성
- ⬜ 영토 확보 → 고유 자원 매일 자동 수급
- ⬜ 생산 건물 3종 업그레이드 + 정보 패널
- ⬜ 본진 패널 — 주민 수 증가 + 다른 건물 레벨 상한 해제
- ⬜ 마법 연구소 — 마나석 소모 스킬 업그레이드
- ⬜ 연금술사의 집 — 마나석 ↔ 자원 교환, 본진 업그레이드 시 효율 상승
- ⬜ 버프 타일 위에 설치한 타워의 사거리가 증가한다
- ⬜ 절차적 맵 생성 → 웨이포인트 이동 → 타워 교전
- ⬜ 스킬 2종(감전 · 버프) 시전 및 쿨타임
- ⬜ 보상 패널 → 특수효과 획득 → 재획득 시 중첩 업그레이드
- ⬜ 소다(스턴) · 초코(슬로우) 상태이상이 정상 적용된다
- ⬜ 중간보스 — 가감속 이동 + HP 30% 이하 1회 회복
- ⬜ 최종 보스 — 본진 돌진 · 방어 태세 · 마력 봉인 · 지속 소환
- ⬜ 공중 유닛 — 경로 무시 곡선 이동, 본진 도달 시 피해
