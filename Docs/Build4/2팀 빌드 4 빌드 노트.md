- 팀명: 2팀 (유유아)
- 빌드 번호: Build 4
- 빌드 일자: 2026-08-07
- 빌드 작성자: 김유찬
- Unity 버전: 6000.3.15f1
- 빌드 플랫폼: Windows
- 빌드 파일명: 2팀 빌드 4.zip
- 기준 기간: 7/31 (빌드 3) ~ 8/7

## 빌드 목표

이번 빌드의 방향은 **"한 판을 이어지게, 화면을 살아 있게"** 다. 빌드 3까지 낮/밤 루프와 성장 축은 자리를 잡았지만, 게임을 끄면 진행이 전부 사라지고 매 판 같은 맵이 나오며 경영 공간에는 아무도 살지 않았다.

- **이어하기와 시드** — 껐다 켜도 이어갈 수 있고, 같은 판을 다시 돌릴 수 있다.
- **전투 공간의 선택지** — 타워 9종 추가, 되돌리기, 드래그 복수 선택.
- **살아 있는 마을** — 주민이 돌아다니고, 배치 · 합성 · 맵 생성에 연출이 붙었다. **밤이 밤처럼 어두워지고 가로등이 켜지며, 낮↔밤 전환에 셀 와이프 연출이 붙었다.**
- **화면 다듬기** — 게임 씬 내 상시 노출되는 메인 화면에 UI 에셋을 처음 적용했다.
- **편의성 · 버그 수정**

> 빌드 3 계획에 있던 **튜토리얼 · 설정 확장 · 자원 개편 · 영토 개편**은 이번 범위에 들어가지 못했다. **UI 에셋 적용**은 상시 노출 화면까지만 진행됐고 패널은 남았다. 다음 빌드로 이월한다.

## 포함된 기능 / 변경 사항

### 이어하기 (신규)

게임을 끄거나 타이틀로 나가도 진행이 남는다.

- **매일 낮이 시작될 때 자동 저장**된다. 밤 도중에는 저장하지 않는다.
- 타이틀에 **"이어하기"** 버튼이 생겼다. 저장된 판이 없으면 버튼이 나타나지 않는다.
- 일차 · 웨이브, 자원, 확보한 영토, 건물과 레벨, 설치한 타워, 본진 체력, 스킬 레벨과 보상으로 얻은 특수효과까지 그대로 복원된다. 전투맵도 저장된 웨이브까지 공개된 상태로 돌아온다.
- 승리하거나 패배하면 저장이 삭제된다 — 이어하기로 결과를 되돌릴 수는 없다.

### 시드로 같은 판 다시 하기 (신규)

- 판을 시작할 때 **시드** 하나가 정해지고, 전투맵과 영토가 그 시드에서 만들어진다.
- 타이틀에서 **시드를 직접 입력**하면 같은 맵 · 같은 영토로 다시 시작할 수 있다. 비워 두면 매번 다른 판이 나온다.
- 밸런스를 볼 때 같은 조건에서 반복 테스트할 수 있고, 재현되는 버그를 남에게 전달할 수 있다.

### 타워 9종 추가 (신규)

기존 8종에 9종이 추가돼 총 **17종**이 됐다.

- **화염 지대 타워** — 바닥에 화염 장판을 깔아 범위 안의 몬스터를 계속 태운다.
- **화염 궁수 타워** — 화살이 맞을 때마다 화상을 남긴다.
- **소이탄 대포** — 착탄 지점에 광역 피해 + 화상을 함께 넣는다.
- **산탄 타워** — 총알 3발을 부채꼴로 한 번에 뿌린다. 유도가 없어 몰려 있을 때 강하다.
- **부메랑 타워** — 투사체가 나갔다 돌아오며 경로상의 적을 관통한다. 오갈 때 각각 한 번씩 맞는다.
- **멀티 인페르노 타워** — 여러 대상에 동시에 레이저를 걸어 계속 지진다.
- **단일 인페르노 타워** — 한 대상만 지진다. 대신 **같은 적을 계속 조준할수록 피해가 크게 불어난다.** 목표를 바꾸면 처음부터 다시 쌓인다.
- **램프업 타워** — 명중할 때마다 **공격 속도가 빨라진다.** 쏘지 않으면 조금씩 식는다.
- **사냥꾼 타워** — 적을 **처치할 때마다 공격력이 오른다.** 웨이브가 끝나면 초기화된다.

> 뒤 3종은 "쏠수록 · 잡을수록 세지는" **성장형** 타워다. 오래 살아남을수록 값어치가 커지므로 배치 위치와 순서가 중요해진다. 다만 **성장은 웨이브를 넘기지 않는다** — 밤이 끝나면 쌓인 것이 전부 풀린다.

부수 변경:

- **캐논 타워가 포물선으로 발사**된다(기존 유도 → 포물선).
- 화상 · 독 · 감속 · 기절이 타워마다 붙는 방식으로 정리돼, 앞으로 상태이상 조합 타워를 늘리기 쉬워졌다.

### 타워 획득 경로 정리 (개선)

- 타워 패널에는 **직접 배치할 수 있는 7종만** 나온다. 나머지 10종은 **합성으로만** 얻는다.
- 개틀링 · 스나이퍼도 합성으로만 얻는 타워가 됐다(기존에는 양쪽 다 가능).
- 합성 결과 타워가 재료 타워의 효과를 물려받는다 — 화상 타워를 재료로 쓰면 결과물도 화상을 남긴다.

### 되돌리기(Undo) (신규)

- **낮 동안의 타워 배치와 합성을 되돌릴 수 있다.** 최근 조작부터 순서대로 되돌아간다.
- 되돌리면 **쓴 자원이 돌아오고**, 합성이었다면 결과 타워가 사라지고 재료 타워가 원래 자리로 복원된다.
- 밤으로 넘어가면 그날의 조작은 확정된다.

### 드래그로 타워 복수 선택 (신규)

- 빈 곳에서 **좌클릭으로 드래그**하면 사각형이 그려지고, 놓는 순간 안에 들어온 타워가 전부 선택된다. 합성 재료를 한 번에 훑을 수 있다.
- 짧게 클릭하면 기존처럼 하나만 선택된다. **Shift + 클릭**으로 하나씩 고르는 방식도 그대로 쓸 수 있다.

### 합성 조작 개선

- 합성 버튼을 누르는 **즉시 재료 타워가 사라진다.** 무엇을 소모하는지 확정된 상태로 자리를 고를 수 있다.
- **배치를 취소하면 재료가 원래 자리로 되돌아온다.** 자원도 돌아온다.
- **합성 족보 패널**이 추가됐다(테스트용) — 어떤 재료로 무엇이 나오는지 전체 목록을 볼 수 있다.

### 마을 주민 (신규)

경영 공간에 주민이 살기 시작했다. 자원을 생산하지는 않고 마을 분위기를 만드는 역할이다.

- 낮에 마을을 **돌아다닌다.** 길과 계단을 따라 대지 · 광장 · 섬을 오가고, 걷다가 가끔 멈춰 쉰다.
- 주민끼리 마주치면 가끔 **대화가 열린다.** 서로 인사하고 번갈아 말하며, 듣는 쪽이 웃기도 한다. **지나가던 주민이 대화에 끼어들어 최대 3명까지** 모인다.
- 주변에 아무도 없으면 **춤을 춘다.** 누가 다가오면 멈춘다.
- **밤이 되면 건물로 들어가고 아침에 다시 나온다.**
- 마우스를 올리면 노란 아웃라인, 클릭하거나 드래그로 고르면 초록 아웃라인이 뜬다.

### 스킬 · 보상 개선

- **보상 카드에 레벨과 수치 변화가 표시**된다. `Lv 0 → Lv 1 / 틱 데미지: 0 → 5` 처럼 고르기 전에 무엇이 얼마나 올라가는지 알 수 있다.
- 스킬 특수효과에 **레벨 상한(3)** 이 생겼다. 만렙에 도달한 효과는 보상 후보에서 빠져, 이미 다 올린 효과가 계속 나오지 않는다.
- **마법 연구소 레벨에 따라 감전 스킬의 착탄 이펙트가 바뀐다.** 연구소를 올린 것이 화면에서 보인다. 연구소의 스킬 범위 상승폭도 크게 올렸다.
- 스킬 조준 표시가 **원기둥 형태**로 바뀌었다. 언덕이나 높낮이가 있는 지형에서도 보이는 범위와 실제 적중 범위가 어긋나지 않는다.

### 연출 (신규)

- **타워 배치** — 입자가 모여들면서 타워가 튀어오르며 등장한다.
- **타워 합성** — 재료가 하얗게 변해 수축하다 터지고, 입자가 되어 떠 있는다. 배치를 확정하면 그 입자가 새 타워로 모여들고, 취소하면 거꾸로 돌아가 재료가 재조립된다. 무엇을 소모했는지 배치하는 내내 보인다.
- **전투맵 생성** — 타일이 지면 아래에서 제각기 다른 속도로 올라오며 가볍게 튀어오른다.
- **밤이 밤처럼 보인다** — 지금까지는 밤이 낮과 거의 구분되지 않았다. 화면 전체가 **어둡고 푸르게** 깔리고 채도가 내려간다. 물빛도 밤 색으로 함께 바뀐다.
- **마을 가로등이 밤에만 켜진다** — 31개가 일제히 들어와 마을 곳곳에 따뜻한 불빛 웅덩이를 만든다. 아침이 되면 전부 꺼진다.
- **낮 ↔ 밤 전환 연출** — 화면을 정사각 셀로 나눠 **우하단에서 좌상단으로 한 칸씩 뒤집으며** 밤으로 넘어간다. 낮으로 돌아올 때는 반대 방향이다. 전환 중에도 주민과 몬스터는 계속 움직인다.

### UI 에셋 적용 — 상시 노출 화면 (신규, 부분 적용)

기본 Unity UI 그대로였던 화면에 처음으로 게임 에셋이 들어갔다. 이번에는 **게임 화면에 항상 떠 있는 부분**까지만 적용했다.

- 상단 자원 표시, 일차 · 웨이브 표시, 본진 체력 바
- 하단 타워 선택 바와 스킬 슬롯
- 배속 · 되돌리기 · "다음"(낮 종료) 등 상시 버튼

**클릭해서 여는 패널들은 아직 기본 UI 그대로다** — 건물 정보 · 업그레이드, 본진, 마법 연구소, 연금술사 상점, 타워 정보, 합성, 보상 선택, 설정, 게임 오버 / 클리어. 다음 빌드에서 이어서 적용한다.

### 그림 톤 통일 (신규)

- 경영 공간에 **하드 컷 셸 셰이딩**을 적용했다. 그림자가 부드러운 그라데이션이 아니라 딱 끊기는 면으로 나와 2D 그림에 가까운 느낌이 된다.
- 마을 오브젝트의 재질을 전부 새 톤으로 교체했다.
- **픽셀 필터가 적용되어 있다.**

### 버그 수정

- 웨이브가 등록한 순서대로 진행되지 않던 문제
- 타일 높낮이에 따라 스킬 조준 표시가 어긋나던 문제
- 타워를 배치하는 중에 설정이나 "다음" 버튼을 누르면 고스트가 그대로 남던 문제
- 산탄처럼 빠른 투사체가 몬스터를 그냥 통과해 버리던 문제
- 부메랑이 같은 적을 한 번 지나가면서 두 번 때리던 문제

## 실행 방법

빌드 3에서 바뀐 부분과 신규 조작만 **굵게** 표시.

- 진입 씬: TitleScene → "게임 시작" 버튼 → GameScene(경영 공간)
  - **"이어하기"** — 저장된 판이 있으면 버튼이 뜨고, 저장된 낮부터 재개된다
  - **시드 입력** — 시드를 넣고 시작하면 같은 맵 · 같은 영토가 나온다. 비우면 무작위
- 카메라: WASD 또는 우클릭 드래그로 이동, 휠로 줌 인/아웃
- 미니맵: 우측 미니맵에 현재 카메라 시야가 사각 라인으로 표시, 좌클릭으로 카메라 이동
- 경영 공간 영토 확장: 확장 가능한 영토 노드 호버 → 좌클릭으로 확보. 확보한 영지는 매일 낮 전환 시 고유 자원 자동 수급
- 경영 공간 건물
  - 생산 건물(나무꾼의 집 · 광산 · 농장): 클릭 → 정보 패널 → 업그레이드
  - 마법 연구소: 스킬 업그레이드 (**레벨에 따라 감전 착탄 이펙트가 바뀐다**)
  - 연금술사의 집: 마나석을 자원으로 교환
  - 본진: 주민 수 증가 및 업그레이드
- **주민**: 낮에 마을을 돌아다닌다. 호버하면 노란 아웃라인, 클릭 · 드래그로 고르면 초록. 밤에는 건물로 들어간다
- 주민 배치: 경영 패널 생산 라인에서 `+`/`-`로 배정 (배정한 만큼 화면의 주민이 줄어든다)
- 타워 배치: 하단 타워 버튼 클릭 → 고스트가 마우스를 따라다니고 배치 가능한 타일에만 설치
  - **타워 패널에는 직접 배치용 7종만 있다.** 나머지 10종은 합성으로만 얻는다
- 타워 합성: 배치된 타워를 **Shift + 클릭 또는 빈 곳에서 좌클릭 드래그(사각형)** 로 복수 선택 → 합성 타워 버튼 클릭하여 배치
  - **버튼을 누르는 순간 재료가 사라지고, 배치를 취소하면 되돌아온다**
- **되돌리기(Undo)**: Undo 버튼으로 낮 동안의 배치 · 합성을 최근 순서대로 되돌린다. 자원도 환원된다
- **합성 족보 패널**(테스트용): 레시피 전체 목록 확인
- 밤 전환: 우측 위 "다음" 버튼 클릭 → 전투 공간 맵 생성 + 웨이브 SO 기준 몬스터 스폰
- 밤 페이즈 스킬: 하단 스킬 UI 선택 → 전투 타일 클릭으로 시전
- 웨이브 클리어: 몬스터 전멸 시 클리어 → 마나석 지급 + 보상 선택 창(**레벨과 수치 변화 표시**) → 다음 낮 (**이 시점에 자동 저장**)
- 배속: x1 / x2 / x4
- 설정: ESC — 언어 변경 / 타이틀로 / 게임 종료
- 테스트용: BalanceTest 패널의 치트 버튼으로 자원/웨이브 상태 강제 조작

### 타워 목록 (17종)

**직접 배치 7종** — 타워 패널에서 자원으로 바로 설치한다.

| 타워           | 역할                                      |
| -------------- | ----------------------------------------- |
| 궁수 타워      | 단일 대상 공격 — 사거리 내 가장 가까운 적 |
| 대포           | 광역 공격 — 착탄 지점 주변 범위 피해      |
| 독마법 타워    | 독 장판 — 범위 내 적에게 지속 피해        |
| 가속의 탑      | 아군 버프 — 범위 내 타워의 공격속도 강화  |
| 초코 폭포 타워 | 감속 장판 — 범위 내 적의 이동속도 감소    |
| 소다 타워      | 단일 대상 공격 + 짧은 스턴                |
| 화염 지대 타워 | 화상 장판 — 범위 내 적에게 화상 부여      |

**합성 전용 10종** — 재료 타워를 골라 합성해야 얻는다. 재료는 **설치되어 있는 타워**여야 한다.

| 타워                  | 필요 재료                             | 역할                                                |
| --------------------- | ------------------------------------- | --------------------------------------------------- |
| 개틀링 타워           | 궁수 타워 ×2                          | 단일 대상 공격 — 빠른 연사                          |
| 스나이퍼 타워         | 궁수 타워 ×1 + 대포 ×1                | 단일 대상 공격 — 멀리 있는 적에게 강력한 한 방      |
| 트리플 샷 타워        | 궁수 타워 ×3                          | 부채꼴로 탄환 3발을 동시에 직선으로 발사해 타격한다 |
| 부메랑 타워           | 궁수 타워 ×1 + 대포 ×2                | 관통 타격 — 던진 방향으로 나갔다 되돌아온다         |
| 화염 궁수 타워        | 궁수 타워 ×1 + 화염 지대 타워 ×1      | 단일 대상 지속 피해 — 명중 시 화상                  |
| 소이탄 대포           | 대포 ×1 + 화염 지대 타워 ×1           | 광역 화상 — 착탄 지점에 범위 피해 + 화상            |
| 멀티 인페르노 타워    | 개틀링 타워 ×2 + 독마법 타워 ×1       | 다중 지속딜 — 여러 적을 동시에 레이저로 지진다      |
| 램프업 타워       | 개틀링 타워 ×1 + 가속의 탑 ×1         | 성장형 속사 — 공격할수록 공격 속도가 빨라진다       |
| 사냥꾼 타워       | 대포 ×1 + 스나이퍼 타워 ×1            | 성장형 저격 — 처치할수록 공격력이 오른다            |
| 단일 인페르노 타워 | 멀티 인페르노 타워 ×1 + 스나이퍼 타워 ×1 | 단일 집중 지속딜 — 같은 적을 오래 조준할수록 급격히 강해진다 |

> **여러 단계를 거치는 합성이 있다.**
> - **멀티 인페르노 타워 · 램프업 타워**는 2단계다 — 재료인 개틀링 타워가 합성 전용이라 궁수 타워를 먼저 개틀링으로 만들어야 한다.
> - **사냥꾼 타워**도 2단계다 — 재료인 스나이퍼 타워가 합성 전용이다.
> - **단일 인페르노 타워는 3단계다** — 멀티 인페르노(2단계)와 스나이퍼(1단계)를 각각 만든 뒤에야 합성할 수 있다. 궁수 타워 기준으로는 6기가 필요하다.
>
> 재료는 **요구량보다 많이 선택해도 된다.** 필요한 개수만 소모되고 남는 타워는 그대로 남는다.
>
> 궁수 3기를 고르면 **개틀링(궁수×2)과 산탄(궁수×3) 버튼이 함께 뜬다.** 재료 수가 결과물의 성격과 대응하도록 의도한 것이며, 둘 중 원하는 쪽을 고르면 된다.

## 알려진 이슈 / 제약사항

- ## 게임플레이
  - **번개사슬 타워는 이번 빌드에서 제외했다** — 구현 난이도가 높아 보류. 다음 빌드 이후 재검토한다
  - 직접 배치 목록을 11종 → 7종으로 줄인 것은 **팀 합의 전이다.** 되돌릴 수 있다
  - 아처 3기를 고르면 개틀링 · 산탄 버튼이 함께 뜬다 — 재료 수가 결과물의 성격과 대응하도록 의도한 것
  - 보스 패턴 수정 · 자원 이름 개편은 이번 범위에 없다
  - 타워 철거가 없어 **되돌리기가 유일한 회수 수단**이다
  - 소다 타워를 여러 기 깔아도 기절 효과가 겹치지 않아 2기째부터는 기여가 거의 없다
  - **주민이 춤추는 것을 못 볼 수 있다** — 넓은 테스트 공간 기준으로 조건을 맞춰서, 마을이 좁으면 조건이 성립하지 않는다
  - 주민을 들어서 건물에 놓는 배치 조작은 아직 없다(패널 `+`/`-` 만)
  - 현재 캐논 타워가 공중유닛을 타겟팅 하지만 데미지는 들어가지 않는다
- ## 연출 / 비주얼
  - 타워 배치 · 합성 연출은 **아트 방향 확정 전 임시 버전**이다
  - 셸 셰이딩은 **경영 공간에만** 적용됐다 — 전투 공간과 UI는 아직 이전 톤
  - **UI 에셋은 상시 노출 화면까지만 적용됐다.** 클릭해서 여는 패널들은 아직 기본 Unity UI라 화면 안에서 톤이 섞여 보인다. 아이콘 · 폰트 교체도 다음 빌드 범위
  - **밤 어둡기는 경영 공간 기준으로 맞췄다** — 전투 공간은 맵이 실행 중에 만들어져 편집 화면에서 확인할 수 없어, 어두워진 상태에서 몬스터 · 타워 · 경로가 잘 보이는지는 **플레이로 확인해야 한다**
  - 가로등은 그림자를 만들지 않는다(31개가 각자 그림자를 잡으면 감당이 안 된다). 빛이 닿는 범위도 좁게 잡혀 있다
  - 최대로 줌 아웃하면 주민이 점처럼 보인다
  - 물에 실제로 닿아 있지 않은데 화면상 닿아 보이면 거품이 생긴다 (빌드 3에서 이월)
