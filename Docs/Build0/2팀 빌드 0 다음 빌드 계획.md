## 다음 빌드에서 추가할 기능

### 전투 공간

- 전투 공간 확장 시 영토 이어짐
- 싸이클 구조 없이 확정적으로 30개(임시 웨이브 수)로 경로 생성

### 경영 공간

- 경영 공간 베이스 프리팹 구성(본진, 기초 건물, 업그레이드 건물)
- 경영 공간 그래프 기반 영토 확장 시스템
- 주민 배치 시스템(건물 + UI 패널)

### 낮/밤 시스템

- 버튼 클릭 시 낮 밤 전환 연출
- 버튼 클릭 시 이벤트 호출
- 낮 -> 밤
- - 주민 배치에 따라 자원 획득
- 밤 -> 낮
- - 주민 배치 초기화
- - 웨이브 수 증가

### 데이터 테이블

- 데이터 테이블 매니저 작성
- CSV파일 SO 형태로 전환
- 자원, 몬스터 데이터 구조 설계

### 마우스 매니저

- 마우스 클릭 시 타워 프리팹이 마우스를 따라다님
- 마우스 호버 시 이벤트 호출

### 타워 배치 시스템

- 전투 공간에서 타워를 배치할 수 있는 타일에 타워 배치 가능
- 마우스가 타워 버튼을 클릭하면 마우스 포인터에 타워 생성
- 마우스가 타워 배치 가능한 타일을 클릭하면 타워 배치

### 몬스터 및 타워

- 몬스터와 타워가 서로 데미지를 입히는 구조 구현
- 몬스터가 웨이포인트를 따라 이동
- 몬스터 hp가 0이 되면 사망
- 몬스터 본진 도착 시 공격 상태

### 전체적인 게임 루프

- 특정 웨이브를 막아내면 게임 승리
- 본진 HP가 0이 되면 게임 종료
