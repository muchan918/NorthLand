# BalanceTestPanel 버튼 복원

**BalanceTestPanel** 버튼 재연결에 대한 결정을 기록한 문서. UI 표시 순서는 `Docs/Core/UIZOrder.md` §4(`UICanvas` 내부 sibling 7번)를 따른다.

> **상태**: 결정 완료(2026-08-07) — 출시 전 제거/제한 여부는 미정

## 1. 결정 사항

- BalanceTestPanel 버튼 재연결은 **의도적인 복원**이다.
- 테스트 편의를 위해 **일반 빌드**에서도 **F4** 키를 통해 접근할 수 있도록 유지한다.

## 2. 미해결 항목

- **출시 전 제거 또는 제한 여부**: 별도로 결정할 예정. 결정되면 이 문서를 갱신하고 위 상태 줄을 갈아 넣는다.
