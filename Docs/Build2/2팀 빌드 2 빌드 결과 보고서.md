# 2팀 빌드 2 빌드 결과 보고서

- 팀명: 2팀 (유유아)
- 빌드 번호: Build 2
- 테스트 일자: 2026-07-24
- 테스트 환경
  - OS: Windows 11

> **✅** 정상 동작 / **⚠️** 부분 동작 / **❌** 미흡 / **⬜** 미확인

## 테스트 결과 요약

- 핵심 루프 동작 여부
  - **낮 → 밤 → 웨이브 클리어 → 보상 → 다음 낮**으로 이어지는 한 사이클이 디버깅용 임시 버튼 없이 자동으로 도는 것을 확인했다. 빌드 1에서 임시 버튼("웨이브 성공/실패/보스 처치")으로 대체하던 웨이브 종료 판정이 정식 로직으로 대체됐다.
  - 경영: 영토 확보 → 고유 자원 자동 수급 → 주민 배치 → 생산 건물 업그레이드(최대 레벨·자원 부족 판정 포함)까지 정상 동작.
  - 전투: 절차적 맵 생성 → 웨이브 SO 기반 스폰 → 웨이포인트 이동 → 타워 6종 교전 → 스킬 시전 → 본진 피해·게임오버까지 정상 동작.
  - 성장: 웨이브 클리어 시 마나석 지급 + 보상 패널 → 스킬 특수효과 획득 → 동일 보상 재획득 시 추가 업그레이드까지 확인.
- 종합
  - 기능 단위 동작은 전 항목 통과했으나, **완성도·편의성 측면의 개선 요청 12건과 버그 4건**이 접수됐다

## 기능별 테스트 결과

### 씬 흐름

- ✅ TitleScene → "게임 시작" 버튼 → GameScene 전환이 정상 동작한다

### 자원

- ✅ 게임 시작 시 타워를 배치할 수 있을 만큼의 초기 자원이 지급되어 있다
- ✅ 타워 배치 시 비용만큼 자원이 차감된다
- ✅ 자원이 부족하면 해당 타워 버튼이 비활성화된다
- ✅ 웨이브 클리어 시 마나석 10이 지급된다
- ✅ 확보한 영지의 고유 자원이 매일(낮 전환 시) 자동 수급된다

### 경영 공간 - 영토

- ✅ 확장 가능한 영토 노드가 표시되고, 호버 시 해당 영지의 자원 정보 툴팁이 뜬다
- ✅ 노드를 선택하면 확보 연출과 함께 땅 에셋이 나타난다
- ✅ 확보된 영토 사이에 배 왕복 연출이 표시된다

### 경영 공간 - 건물 / 업그레이드

- ✅ 건물에 호버하면 툴팁, 클릭하면 정보 패널(레벨·증감·비용)이 뜬다
- ✅ 업그레이드 버튼으로 생산 건물을 업그레이드할 수 있고 자원이 차감된다
- ✅ 최대 업그레이드 완료되면 업그레이드 불가된다
- ✅ 업그레이드 후 주민 1인당 획득량이 실제로 증가한다
- ✅ 자원이 부족하면 업그레이드가 되지 않는다

### 낮/밤 전환

- ✅ 낮/밤 전환 시 조명이 바뀐다
- ✅ 밤 전환 시 전투 공간 맵이 생성되고 공개 연출이 재생된다
- ✅ 웨이브 카운트가 1부터 시작하고 클리어마다 1씩 증가한다

### 전투 공간 - 맵 / 몬스터

- ✅ 절차적으로 생성된 맵의 웨이포인트를 따라 몬스터가 이동한다
- ✅ 몬스터가 웨이브 SO에 정의된 구성·간격대로 스폰된다
- ✅ 몬스터 이동 속도가 EnemyAsset 데이터를 따른다
- ✅ 몬스터의 이동/공격/피격/사망 애니메이션(FSM)이 실제 전투와 맞물려 재생된다

### 전투 공간 - 타워 배치

- ✅ 타워 패널에서 종류별 타워를 선택해 배치할 수 있다
- ✅ 고스트 프리팹이 마우스를 따라다니고 배치 불가 타일에는 설치되지 않는다
- ✅ 지형(벽면 등)과 무관하게 타워가 타일 높이에 맞춰 설치된다

### 전투 시스템 - 타워 종류

- ✅ 아처 타워가 사거리 내 몬스터를 공격한다
- ✅ 캐논 타워의 호밍 아크 투사체가 정상 명중한다
- ✅ 개틀링 타워가 빠른 연사로 공격한다
- ✅ 스나이퍼 타워가 장사거리로 공격한다
- ✅ 도트딜 디버프 타워의 효과가 몬스터에게 적용된다
- ✅ 공속 버프 타워의 효과가 주변 타워에 적용되고, 중첩 시 합산된다

### 밤 페이즈 - 스킬

- ✅ 밤이 되면 타워 패널이 스킬 UI로 교체된다
- ✅ 감전 스킬 선택 시 범위 인디케이터가 표시되고, 클릭한 위치에 시전된다
- ✅ 시전 범위 내 몬스터가 실제로 피해를 입는다
- ✅ 버프 스킬 사용 시 설치된 모든 타워에 공격력·공격속도 증가가 적용된다
- ✅ 스킬 쿨타임이 정상 동작한다

### 웨이브 종료 / 보상

- ✅ 스폰된 몬스터를 모두 처치하면 웨이브 클리어로 판정된다(임시 버튼 없이)
- ✅ 보상이 있는 웨이브는 낮으로 넘어가기 전에 보상 패널이 뜬다
- ✅ 선택한 보상(스킬 특수 효과)이 다음 웨이브에 실제로 적용된다
- ✅ 동일 보상을 다시 획득하면 수치·효과가 추가로 업그레이드된다
- ✅ 본진 HP가 0이 되면 GameOverUI가 표시되고, 몬스터가 Idle로 멈춘다

### UI / 미니맵

- ✅ 본진 HP UI가 피해에 맞춰 갱신된다
- ✅ 몬스터 개별 HP 슬라이더가 표시·갱신된다
- ✅ 미니맵에 현재 카메라 시야가 사각 라인으로 표시되고 카메라 이동에 맞춰 따라간다
- ✅ 미니맵을 좌클릭하면 해당 위치로 카메라가 이동한다

### 밸런스

- ✅ 그러미 몬스터 3종의 체력/속도 차이가 체감된다
- ✅ 초반 웨이브를 기본 자원으로 방어 가능한 수준이다
- ✅ BalanceTest 치트 패널의 버튼이 의도대로 동작한다

## 개선 사항

> 동작은 하지만 개선이 필요한 항목

- 타이틀 씬 게임 종료 버튼 기능 구현
- 타워 패널에 버튼 추가해서 전체 타워를 볼 수 있는 기능
- 타워 패널에 버튼 호버 시 타워 코스트 표시
- 경영 공간 건물 가시성 개선
- 강제적인 경영 공간 영토 확장 - 주민 배치 - 낮 종료 프로세스 개선
- 시드 값 랜덤 적용하여 매판 새로운 게임이 되도록 개선
- 스킬 특수효과 범위 표시 및 증가
- 현재 보상 레벨 및 수치 표시
- 타워 설치할 때 표시되는 사거리 범위(라인 렌더러) 두께 증가
- 스킬 쿨타임 표시
- 전투 타일 시작 부분 침식 금지
- 타워 클릭 시 사거리 표시

## 발견된 버그 및 이슈

> 테스트 중 발견한 버그

- 경영 공간 확장 가능한 영토(소용돌이)가 특정 상황에서 보이지 않음
- 타워 패널 휠 방향 불일치 
- UI 순서 설정(미니맵, 보상 패널, 게임 결과 패널)
- water shader 부자연스러운 거품 표시
- 타워 패널에서 타워 선택 후 저녁으로 넘어가면 타워 설치 가능
- 보상 선택창에서 미니맵을 클릭한 후 보상을 선택하면 미니맵이 움직임
- 보상 선택창이 떠있는 상태에서 미니맵으로 이동 불가능
