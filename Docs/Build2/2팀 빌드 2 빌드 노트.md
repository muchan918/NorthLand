## 빌드 목표

- **에셋 적용**: 영토·타일·건물·몬스터 전부 에셋 적용(UI 제외)

  - 몬스터 에셋 선정 및 프리팹화

- **게임 시작**: 기본 자원을 지갑(ResourceWallet)에 채우는 초기화 로직

- **낮 페이즈**

  - 업그레이드 시스템(자원+마나석 소모 판정)

- **밤 페이즈**

  - 플레이어 스킬(클릭 발동 + 범위 판정 + 데미지) UI/로직
  - 웨이브 세트 완주/실패 판정을 정식 로직으로 연결(임시 버튼 제거)

- **웨이브 클리어 → 낮 전환**: 마나석 자원 개념 추가(웨이브 클리어 보상으로 지급)

- **공통/기반 시스템**

  - 병사 배치 시스템 — 회의 후 문서 정리

목표 대비 수정 및 추가된 사항은 다음과 같다.

- **병사 시스템 삭제**
  - 병사 시스템이 스킬과 비슷한 시스템이라 판단
  - 병사를 업그레이드 용도로 사용하기엔 자원과의 차별점을 못 느낌
- **웨이브 클리어 보상 → 스킬 특수효과 부여 시스템으로 전환**
  - 웨이브마다 보상 여부를 판단
  - 보상이 있는 웨이브면 모든 몬스터 처치 시 낮으로 넘어가기 전에 보상 패널을 띄움
  - 보상 획득 시 기본 스킬을 업그레이드하는 시스템
  - 동일 보상을 다시 획득하면 데미지 수치 및 효과가 추가로 업그레이드
- **경영 공간 영토 의미 변경**
  - "확보 시 패시브 효과 지급" → "미개척 영지, 확보 시 특수 자원(금·사파이어·루비·다이아)을 매일 자동 수급"
- **미니맵 추가**(목표 외 신규)
  - 미니맵 + 현재 카메라 시야를 나타내는 사각 라인 + 미니맵 좌클릭 카메라 이동

**요약**: 빌드 1의 목표였던 초기 자원 지급 → 타워 배치 비용 차감 → 웨이브 SO 기반 스폰 → 플레이어 스킬 시전 → 웨이브 클리어 정식 판정 → 마나석·보상 지급 → 다음 낮으로 이어지는 **한 사이클이 임시 버튼 없이 자동으로 도는 것을 확인**했다. 빌드 1에서 미흡했던 4건(초기 자원 미지급, 타워 배치 자원 차감, 보스 처치 지연 분기, 웨이브 성공 시 몬스터 정리)은 모두 해소됐다. 에셋 적용은 경영 공간(본진·섬 지형·영토 노드·배 연출)은 완료됐고 전투 공간(타일·타워·몬스터)은 일부만 교체돼 부분 완료다. 병사 배치 시스템은 회의 결과 **설계에서 제외**했고, 낮/밤 라이트의 UniTask Lerp 전환은 미착수다.

## 실행 방법

- 타워 코스트 목록(설계 이슈가 발생하여 넣지 못함)
  - archer_tower: 나무 20
  - cannon_tower: 나무 20, 철 10
  - poison_tower: 나무 40, 철 20, 다이아 5
  - haste_tower: 나무 35, 철 25
  - gatling_tower: 금 5, 철 20
  - sniper_tower: 루비 5, 사파이어 5

- 진입 씬: TitleScene → "게임 시작" 버튼 → GameScene(경영 공간)
- 카메라: wasd 또는 우클릭 드래그로 이동, 휠로 줌 인/아웃
- 미니맵: 우측 미니맵에 현재 카메라 시야가 사각 라인으로 표시되며, 미니맵을 좌클릭하면 해당 위치로 카메라가 이동한다
- 경영 공간 영토 확장: 확장 가능한 영토 노드에 호버 → 좌클릭으로 확보. 확보한 영지는 매일 낮 전환 시 고유 자원을 자동 수급한다
- 건물 정보 / 업그레이드: 배치된 건물(나무꾼의 집·광산·농장만 적용)에 호버 시 툴팁, 클릭 시 정보 패널(레벨·증감·비용 표시) → 업그레이드 버튼 클릭 시 효과 적용 및 자원 차감
- 주민 배치: 경영 패널 생산 라인에서 `+`/`-`로 배정
- 타워 배치: 하단 타워 버튼 클릭 → 고스트 프리팹이 마우스를 따라다니고 배치 가능한 타일에만 설치. 자원이 부족하면 버튼이 비활성화된다
- 밤 전환: 우측 위 "다음" 버튼 클릭 → 전투 공간 맵 생성 + 웨이브 SO 기준 몬스터 스폰
- 밤 페이즈 스킬: 하단 스킬 UI 선택 → 전투 타일 클릭으로 시전
  - 감전 스킬 — 사용 시 범위 인디케이터 생성 후 범위 피해
  - 버프 스킬 — 사용 시 설치된 타워에 효과 부여(기본 효과는 공격력 증가·공격속도 증가)
- 웨이브 클리어: 스폰된 몬스터를 모두 정리하면 클리어 → 마나석 지급 + 보상 선택 창(보상 존재 시) → 다음 낮
- 테스트용: 좌측 BalanceTest 패널의 치트 버튼으로 자원/웨이브 상태를 강제 조작 가능
