# 2팀 빌드 5 다음 빌드 계획

- 팀명: 2팀 (유유아)
- 기준 빌드: Build 5
- 다음 빌드 목표 일자: (미정)

## 방향

**"수치를 확정하고, 화면과 안내를 채운다."** 밸런스를 코스트부터 다시 잡아 다른 수치의 기준을 세우고, 그 위에 UI · 사운드 · 튜토리얼을 올린다.

## 먼저 고칠 버그 (빌드 5 테스트)

- 트리플 샷 타워가 몬스터를 못 때린다
- 레시피 족보와 합성 가능 목록이 다르게 나온다 → §1로 함께 처리
- 마지막에 고른 슬롯이 재실행 시 복원되지 않는다
- BGM 크로스페이드 미동작
- 보상 카드 이펙트 누락
- 가속 타워 셰이더가 보라색으로 보임 / Water Shader 거품 어색함
- 스타트맵(무지개 포털 뒤쪽) 삭제

## 1. 도감 패널

지금은 테스트용이고, 합성 패널과 목록이 어긋나 족보에 뜬 타워가 합성되지 않는다.

- **레시피 정본을 하나로 통합** — 합성 패널과 도감이 같은 목록을 본다
- 타워 19종의 **정보 열람**(이름 · 역할 · 스탯 · 아이콘)
- **합성 경로 표시** — 재료와 단계(2~3단계 포함)를 도감만 보고 알 수 있게
- 정식 UI로 승격 (§4 UI 에셋과 세트)

## 2. 세이브 데이터 비동기 전환

- 저장 · 로드를 비동기로 교체 (저장 순간 프레임이 멈추지 않게)
- 저장 중 중복 저장 · 씬 전환 방지 처리
- 슬롯 자동 복원 버그를 이 작업에서 함께 해결

## 3. 밸런스 — 코스트 먼저

**순서를 지킨다. 타워 코스트를 확정하지 않으면 나머지 수치가 기준을 잃는다.**

1. **타워 코스트 확정** — 19종의 배치 · 합성 비용을 성능과 함께 정한다 (지금은 코스트를 고려하지 않은 상태)
2. **자원 순환** — 확정된 코스트를 기준으로 수급량 · 건물 산출 · 업그레이드 비용. **설탕 소비처(주민 수 증가)** 확정
3. **몬스터** — 웨이브별 체력 · 수량을 자원 곡선에 맞춘다
4. **스킬 · 업그레이드** — 감전 수치, 보상 5종, 마법 연구소 · 본진 업그레이드 폭

추가 확인 항목

- 성장형 3종(램프업 · 사냥꾼 · 단일 인페르노) 실측
- 미사일 계열 2종 기준 편입
- 번개사슬 타워 배선 또는 폐기 결정

## 4. UI 에셋 적용

- **픽셀 톤이 남은 화면을 파스텔로 일괄 교체** (현재 두 톤 혼재)
- **타워 아이콘 19종** — 지금은 궁수 1종뿐, 패널 6칸이 빈 테두리
- 자원 표기에 아이콘 + 이름/툴팁 보강 (아이콘 단독이라 못 읽히는 문제)
- 도감 패널 정식 UI (§1)

## 5. 사운드 적용

- **타워 발사 · 명중 · 배치 · 합성 · 버튼 · 웨이브 클리어 SFX** (현재 스팅어와 주민 목소리뿐)
- 스킬 착탄음을 볼륨 제어 대상에 편입
- BGM 크로스페이드 수정

## 6. 설정

- **볼륨 슬라이더 3채널** (값은 이미 저장·영속화됨 — UI만 없다)
- 카메라 이동 · 줌 감도 조절 (줌 배율에 감도가 따라가지 않는 문제 포함)
- 타이틀 · 인게임 양쪽 동일 동작

## 7. 튜토리얼

UI · 이름 · 밸런스가 굳는 이번 빌드가 착수 시점이다.

- 범위: **1일차 낮 ~ 웨이브 1 클리어** (Issue #271)
- 안내 대상: 주민 배치 → 건물 업그레이드 → 낮 종료 → 타워 배치 → 합성 → 감전 시전
- 고정 시드를 써서 별도 맵은 만들지 않는다

## 8. 경영 공간 채우기

- **건물 시인성** — 건물 위 아이콘 표시, 클릭 시 카메라 이동
- 주민을 들어 옮기는 조작에 연출 추가
- 빈 공간 · 어색한 동선 정리

## 9. 타워 에셋 적용

- 현재 4종(아처 · 캐논 · 스나이퍼 · 트리플 샷) → **나머지 15종 순차 적용**
- 적용 시 풋프린트 변경 여부 확인 (스나이퍼 2x2 사례)
- 툰 셰이딩을 전투 공간까지 확장 — 경영 공간과 톤이 갈려 있다

## 정해야 할 것

- 타워 코스트 기준표 — §3의 선행 조건이자 이번 빌드 전체의 기준
- 설탕 소비처 확정 (주민 수 증가로 갈 것인지)
- 번개사슬 타워 배선 / 폐기
- 직접 배치 로스터 7종 사인오프 (여전히 미완)
- 타워 에셋 19종 조달 일정 — §9와 §4 아이콘이 여기에 묶인다
- 튜토리얼 범위를 1웨이브로 확정할 것인지
