# 2팀 빌드 5 플레이 가이드

# 중요!!!!

현재 스타트 맵 길이에 대한 밸런스를 잡는 상황이라 본진 부분을 경로 중간으로 땡겨왔습니다. 무지개 포탈을 본진 성문이라고 생각하고 플레이 해주세요. 무지개 포탈 뒷부분에 타워를 지으면 안됩니다.

---

### 게임 설명

한 판 = **15웨이브**입니다. 낮에 마을을 키우고, 밤에 몰려오는 몬스터를 타워로 막습니다.
15웨이브를 버티면 승리, 본진 체력이 0이 되면 게임 오버입니다.

---

## 조작

| 조작                     | 입력                                      |
| ------------------------ | ----------------------------------------- |
| 카메라 이동              | WASD, 마우스 우클릭 드래그, 미니맵 좌클릭 |
| 카메라 확대/축소         | 마우스 휠                                 |
| 선택                     | 좌클릭                                    |
| 타워 및 주민 다수 선택   | 좌클릭 드래그                             |
| 배치/시전 취소           | 마우스 우클릭                             |
| 설정 패널                | ESC                                       |
| 배속(x1/x2/x4), 일시정지 | 화면의 UI 버튼 (단축키 없음)              |
| 되돌리기                 | 우측 위 동그란 화살표 버튼 (단축키 없음)  |

- 되돌리기는 그 날 배치한 타워와 합성한 타워를 되돌릴 수 있습니다.

---

## 자원

현재 플레이에 필요한 자원은 **비스켓**, **초코**, **별사탕** 세 가지입니다.

---

## 플레이에 필요한 기능

- **생산라인 패널**: 좌측 하단의 `+` `-` 버튼을 클릭하여 주민을 배치할 수 있습니다. (웨이브 클리어 시 해당 자원 획득)
- 웨이브를 클리어하면 추가로 **별사탕** 자원을 10개씩 얻습니다.
- 별사탕 자원은 **마법 연구소**에서 스킬을 업그레이드 하거나, **연금술사의 집**에서 자원을 교체할 수 있습니다.
- **주민 수 증가**: 본진 건물을 클릭해서 주민 수를 증가시킬 수 있습니다. (누를수록 비용이 올라가고, 최대 10명까지 늘릴 수 있습니다)
- **비스켓 하우스**(본진 위쪽 건물)를 클릭하면 업그레이드 패널이 나오고, 업그레이드 시 웨이브 클리어 후 얻는 자원량이 증가합니다.
- **초코 나무**(우측 나무)를 클릭하면 업그레이드 패널이 나오고, 업그레이드 시 웨이브 클리어 후 얻는 자원량이 증가합니다.
- **타워 배치**: 하단 타워 패널에서 타워를 고르면 마우스를 따라 반투명 타워가 따라옵니다. 원하는 타일에 좌클릭하면 배치됩니다. (사탕이 있는 타일에는 지을 수 없습니다)
- **타워 합성**: 설치된 타워를 `Shift` + 좌클릭으로 여러 개 선택하거나, 빈 곳에서 좌클릭 드래그로 범위 선택하면 합성 가능한 타워 버튼이 뜹니다. 버튼을 누르고 원하는 자리에 배치하면 됩니다.
- **되돌리기**: 타워 철거 기능이 없기 때문에, 잘못 지었을 때는 되돌리기 버튼으로만 회수할 수 있습니다. (자원 100% 환불, 낮에만 가능)
- **밤으로 넘어가기**: 우측 위 "다음" 버튼을 누르면 밤이 시작됩니다.
- 밤이 되면 **스킬 패널**이 활성화됩니다. 스킬은 한 종류이고, 해당 범위 내에 피해를 줍니다.
- 특정 웨이브에는 스킬에 특수효과를 주는 **보상**이 나옵니다. 보상은 감전 스킬에 효과를 더하는 시스템입니다.
- 미니맵 하단에 타워 합성 레시피를 볼 수 있는 패널이 있습니다. 보기 불편하지만 합성에 필요한 재료를 볼 수 있습니다.

---

## 알아두면 좋은 점

- 감전은 한 번 쏘면 조준이 풀립니다. 다시 쏘려면 스킬 버튼을 한 번 더 눌러야 합니다.
- 8웨이브부터 공중 유닛(박쥐)이 나옵니다. 현재 버그 이슈로 감전 본체와 폭탄 보상은 공중에 닿지 않고, 전기장 보상은 닿습니다.
- 화면을 확대한 상태에서는 카메라 이동이 다소 빠르게 느껴질 수 있습니다.
