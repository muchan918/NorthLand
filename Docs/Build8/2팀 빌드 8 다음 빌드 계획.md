## 몬스터 종류 추가

20웨이브를 사실상 같은 몬스터 구성으로 채웠다. 웨이브가 길어질수록 **체력 · 이동속도 배율만 커지고 플레이어가 하는 일은 그대로**였다. 공중과 자폭 말고, 타워 배치나 조준 정책을 다시 짜게 만드는 종류가 더 필요했다.

## UI 통일

V3 → V4 → V5로 세 번 갈아엎었지만 패널마다 만든 시점이 달라 끝까지 한 벌이 되지 못했다. **폰트 통일(#499)** 이 마지막까지 남았고, 여백 규칙과 아이콘 화풍도 제각각이다. 화면을 만들기 전에 규격을 먼저 정했어야 했다.
