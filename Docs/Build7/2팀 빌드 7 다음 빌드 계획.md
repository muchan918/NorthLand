- 전투 공간 사운드(스킬, 타워, 몬스터 타격 소리) ✅ (김성수)
- 게임 오버, 게임 승리 ✅ (이재서)
- 폰트 적용
- 웨이브 강해지는 정보 표시 ✅ (김선진)
- 타워 파티클 추가 ✅ (김성수)
- 생산 라인 패널과 마법사의 집 Info UI 분리 ✅ (김선진)
- 버프 타워 사거리 수치가 이상하게 변함 ✅ (김성수)
- 튜토리얼 주민 드래그 단계를 버튼으로도 통과 가능하게 ✅ (김유찬)
- 독 타워 사이즈 줄이기 ✅ (김성수)
- 타워 사거리 표시 불일치 ✅ (김성수)
- 스킬 Indicator 수정 
- 2x2 타워 배치할 때 타일 어떻게 할지 ✅ (김선진)
- 전기장 스킬에 슬로우 추가 ✅ (김유찬)
- 배속 버튼 단축키 추가하거나 아무튼 조작하기 편하게 ✅(이재서)
- 스킬 단축 단축키 ✅(김유찬)
- 초록색은 좋은데 업그레이드 불가할 때 회색보다 빨간색이 더 한눈에 들어올 것 같다
- 업그레이드 건물 패널 비용 충족된 초록색 글씨를 더 잘보이게 만들기 ✅ (김선진) 
- 합성 리스트 아이콘도 같이 띄워지면 가독성이 더 좋을듯 ✅ (이재서)
- 도감에서 타워 분류를 해줬으면 좋겠다 — 깔때기 ✅ (김선진)
- 버프 타일에 설치할 때 수치가 보여줬으면 좋겠음 ✅ (이재서)
- 게임 시작하고 게임 종료할 때 로컬라이제이션 키가 등록 안 됨 ✅(김선진)
- 튜토리얼 시작을 보여주면 좋겠다 ✅(김유찬)
- 미니맵 바로가기 아이콘 배경 색을 눈에 잘 띄는 걸로 ✅(김선진)
