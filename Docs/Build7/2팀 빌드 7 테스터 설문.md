# 2팀 빌드 7 테스터 설문

- 팀명: 2팀 (유유아)
- 대상 빌드: Build 7 (Windows)
- 소요 시간: 플레이 후 설문 5~10분

## 작성 방법

해당하는 항목의 `[ ]` 를 `[x]` 로 바꾸고, **자유 의견** 칸에 하고 싶은 말을 적어주시면 됩니다.
**버그를 찾아달라는 설문이 아닙니다.** 재미있었는지, 무엇을 개선하면 좋을지를 알고 싶습니다.

## 플레이 안내

- zip 압축을 풀고 exe 실행 → 타이틀에서 **세이브 슬롯을 하나 고른 뒤** "게임 시작"
- 처음 시작하면 **튜토리얼**이 진행됩니다
- 카메라: WASD 또는 우클릭 드래그로 이동, 휠로 줌 / ESC로 설정(언어 · 해상도 · 볼륨)
- **한 판은 15웨이브**입니다. 끝까지 못 가도 괜찮습니다.
