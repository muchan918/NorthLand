# NorthLand: Last Stand — Game Design Document

> 낮엔 준비, 저녁엔 수비
> 그리드 기반 타워 디펜스 + 마을 경영 전략 게임

**팀명**: 유유아 (유찬이와 유쾌한 아이들)
**팀원**: 김유찬 · 김선진 · 김성수 · 이재서
**작성일**: 2026.07.08
**버전**: v0.1 (킥오프 발표 기준)

---

## 1. 개요

### 1.1 한 줄 소개
멸망 직전의 마지막 영지에서, 낮에는 자원을 모으고 마을을 경영하며 밤에는 몰려오는 몬스터로부터 본진을 지키는 그리드 기반 타워 디펜스 게임.

### 1.2 장르
타워 디펜스 + 시티빌더(경영 시뮬레이션) 하이브리드, 로그라이크 요소 결합

### 1.3 세계관 / 테마
- **테마**: 중세 판타지
- **배경**: 대륙은 무너졌다. 왕국의 깃발도, 기사단의 맹세도 밤의 대군 앞에 모두 재가 되었다. 마지막 뿌리를 내린 생존자들이 찬란한 태양 아래 희망을 꿈꾼다.
- **낮**: 해가 떠 있는 동안이 기회다. 자원을 모으고, 타워를 세우고, 병력을 준비한다.
- **밤**: 어둠과 함께 몬스터가 몰려온다. 새벽이 올 때까지 버텨야 한다.
- 배경은 저주받은 땅 위에 남은 중세 성곽 마을. 몬스터 테마는 논의 중이며 변경 가능.

## 2. 레퍼런스

3개 레퍼런스에서 부분적 요소를 가져와 통합.

| 레퍼런스 | 차용 요소 |
|---|---|
| **NordHold** | 타워 디펜스 + 마을 경영, 웨이브 사이 자원 채집·건설, 경영·전투 공간 분리 |
| **Slay the Spire** | 노드 기반 경로 선택형 로그라이크 진행 구조 → 경영 영토 확장 시스템에 응용 |
| **명일방주 (Arknights)** | 타워 디펜스 기본 구조, 웨이포인트·자동 방어, 전투 공간 디펜스 |

### 종합 재미 요소
- **경영이 곧 전투력**: 경영 공간에서 확보한 자원으로 전투 공간에 타워를 배치하고 방어선을 구축
- **실시간 전투 참여**: 전투는 자동 진행되지만 플레이어 스킬로 직접 개입 가능
- **로그라이크 요소**: 매 판 새로운 유물/선택지로 타워를 조합해 나만의 빌드 완성

## 4. 핵심 시스템

### 4.1 두 개의 공간 (분리된 이중 확장 구조)
- **경영 공간**: 자원 생산, 주민 배치, 건물 건설, 영토 확장
- **전투 공간**: 타워·병사 배치로 본진 수비
- 두 공간의 영토는 각각 독립적으로 관리되며 동시에 확장 가능

### 4.2 자원 흐름 (RESOURCE FLOW)
자원은 **나무 · 철 · 식량 · 마나석** 4종.

- **나무/철/식량**: 생산 건물에 주민을 배치해 얻는 기본 자원 → 건물 건설, 건물 업그레이드, 병사 훈련, 타워 강화에 사용
- **마나석**: 영토 확장·전투 보상으로 얻는 상위 자원 → 스킬 획득 및 강화에 사용

### 4.3 성장 루프 (GROWTH LOOP)
```
주민 배치 → 자원 생산 → 영토 확장 → 타워/병사 강화
   → 몬스터 침공 방어 → 보상 획득 → 더 강한 성장 → (반복)
```

### 4.4 승패 조건
- **게임 오버**: 전투 중 본진 HP가 0이 되면 해당 Run 종료
- **클리어 조건**: 모든 스테이지를 클리어하고 최종 보스를 처치하면 승리

## 5. 게임 루프 — 하루 2단계 사이클

```
낮(경영) → 밤(수비) → (다음날로 반복)
```

### 5.1 낮 · 경영 (Morning Phase)
목표: 자원을 생산하고 다가올 밤에 대비해 타워·병사를 준비한다.

| 요소 | 내용 |
|---|---|
| 본진 체력 회복 | 낮 시작 시 본진 체력 회복 |
| 주민 배치 | 보유한 주민 수만큼 생산 건물 또는 훈련장에 배치 (배치는 매일 초기화) |
| 건물 건설 | 경영 공간에 새로운 생산 건물 해금 |
| 타워 건설 | 전투 공간에 확보한 자원으로 타워 배치 |
| 경영 영토 확장 | 그래프 노드 중 인접한 영토 하나를 선택 → 즉시 효과 발동, 확장 후 다음 확장 가능 영역 생성. 영토마다 고유 특수 효과 존재 |

### 5.2 밤 · 수비 (Evening Phase)
목표: 준비한 타워·병사와 플레이어 스킬로 몬스터의 침공을 막아낸다.

| 요소 | 내용 |
|---|---|
| 몬스터의 침략 | 정해진 경로를 따라 본진으로 진격, 타워는 사거리 내 적을 자동 공격 |
| 병사 배치 | 웨이포인트에만 배치 가능, 배치 후 위치 변경 불가, 몬스터 이동 저지 담당. 사망 시 교회로 이동 → 다음날 사용 가능한 주민 수 감소 |
| 플레이어 스킬 | 원하는 위치를 지정해 사용 (스킬 선택 → 범위 지정 → 사용), 불리한 전황을 뒤집는 핵심 개입 수단 |
| 보상 | 웨이브 종료 후 3개의 보상 중 하나 선택 → 다음 성장 방향 결정 |

## 6. 세부 시스템

### 6.1 주민 시스템
- 영토 확장을 통해 주민 획득
- 하루가 끝나면 주민 배치는 초기화됨
- 배치처: 자원 생산 건물(나무/철/식량) or 훈련장(병사 생성)

### 6.2 건물 건설 & 타워 배치
- 경영 공간: 새로운 생산 건물 해금
- 전투 공간: 확보한 자원으로 타워 건설
- 낮 동안 경영 공간은 건물을, 전투 공간은 타워를 배치하는 구조로 명확히 분리

### 6.3 경영 영토 확장
- 보유 영토(노란색) 기준 인접 영토(회색)만 선택 가능
- 인접 영토 중 하나 선택 → 새로운 영토 확보 → 다음 확장 가능 영역 생성 (Slay the Spire 노드 선택 구조 응용)
- 각 영토마다 고유 특수 효과 존재, 선택 시 효과 획득

### 6.4 병사 배치
- 웨이포인트에만 배치 가능, 배치 후 이동 불가
- 역할: 타워로 막지 못한 몬스터 저지
- 사망 시 교회로 이동, 다음날 가용 주민 수 감소
- 주민을 자원 생산 vs 병사 훈련 중 어디에 배치할지가 매일의 전략적 선택

#### ⚠️ 검토 중 이슈 (현재 논의 사항)
- **문제 ①**: 병사 배치와 스킬 시스템 간 차별성 부족
- **문제 ②**: 병사만의 전략적 역할이 부족
- **검토 방향 ①**: 스킬 시스템과 병사 시스템 통합 검토
- **검토 방향 ②**: 주민 배치 전략성을 자원 생산 축으로 통합
- **목표**: 병사 시스템은 "주민을 자원 생산과 병사 운용 사이에서 고민하게 만드는 것"이 핵심 목적임을 재확인

### 6.5 스킬 시스템
- 흐름: 스킬 선택 → 범위(위치) 지정 → 사용
- 플레이어가 원하는 위치를 직접 지정하는 위치 지정형 액티브 스킬

### 6.6 보상 시스템
- 웨이브 종료 후 3개 보상 중 1개 선택
- 선택한 보상이 다음 성장 방향을 결정 (로그라이크 빌드 형성의 핵심 축)

## 7. 우리가 생각하는 재미 (Main Attraction)

| 재미 요소 | 설명 |
|---|---|
| TD + 빌드 조합 | 기존 타워 디펜스 장르에 나만의 빌드(운영) 조합을 더한 새로운 재미 |
| 주민 배분 전략 | "오늘은 자원에 투자할지, 훈련장에 배치할지" 매일 고민하는 전략적 재미 |
| 랜덤의 재미 | 영토 효과와 보상을 매 게임 랜덤으로 얻는 리플레이 재미 |
