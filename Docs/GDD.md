# NorthLand: Last Stand — Game Design Document

> 낮엔 준비, 저녁엔 수비
> 그리드 기반 타워 디펜스 + 마을 경영 전략 게임

**팀명**: 유유아 (유찬이와 유쾌한 아이들)
**팀원**: 김유찬 · 김선진 · 김성수 · 이재서
**작성일**: 2026.07.15
**버전**: v0.2 (3주차 빌드 기준)

## 1. 개요

### 1.1 한 줄 소개

멸망 직전의 마지막 영지에서, 낮에는 자원을 모으고 마을을 경영하며 밤에는 몰려오는 몬스터로부터 본진을 지키는 그리드 기반 타워 디펜스 게임.

### 1.2 장르

타워 디펜스 + 시티빌더(경영 시뮬레이션) 하이브리드, 로그라이크 요소 결합

### 1.3 세계관 / 테마

- **테마**: 중세 판타지
- **배경**: 대륙은 무너졌다. 왕국의 깃발도, 기사단의 맹세도 밤의 대군 앞에 모두 재가 되었다. 마지막 뿌리를 내린 생존자들이 찬란한 태양 아래 희망을 꿈꾼다.
- **낮**: 해가 떠 있는 동안이 기회다. 자원을 모으고, 타워를 세우고, 병력을 준비한다.
- **밤**: 어둠과 함께 몬스터가 몰려온다. 새벽이 올 때까지 버텨야 한다.
- 배경은 저주받은 땅 위에 남은 중세 성곽 마을. 몬스터 테마는 논의 중이며 변경 가능.

### 1.4 비주얼 컨셉

- **오쏘그래픽 카메라 + "움직이는 미니어처(디오라마)" 룩** — 2.5D보다 미니어처 착시 우선.
- 구현 수단: 틸트-시프트 블러(스크린 Y 밴드) + 컬러 그레이딩(채도·따뜻한 톤) + 강한 키 라이트 + 툰 셰이더(소프트 램프).
  상세 설계·확정 결정은 `Docs/Rendering/VisualLookPipeline.md`(#148) 참조.
- 세부 튜닝 수치(채도·블러 밴드·라이트)는 TBD — 구현 중 스크린샷 비교로 확정.

## 2. 레퍼런스

3개 레퍼런스에서 부분적 요소를 가져와 통합.

| 레퍼런스                 | 차용 요소                                                                 |
| ------------------------ | ------------------------------------------------------------------------- |
| **NordHold**             | 타워 디펜스 + 마을 경영, 웨이브 사이 자원 채집·건설, 경영·전투 공간 분리  |
| **Slay the Spire**       | 노드 기반 경로 선택형 로그라이크 진행 구조 → 경영 영토 확장 시스템에 응용 |
| **명일방주 (Arknights)** | 타워 디펜스 기본 구조, 웨이포인트·자동 방어, 전투 공간 디펜스             |

### 종합 재미 요소

- **경영이 곧 전투력**: 경영 공간에서 확보한 자원으로 전투 공간에 타워를 배치하고 방어선을 구축
- **실시간 전투 참여**: 전투는 자동 진행되지만 플레이어 스킬로 직접 개입 가능
- **로그라이크 요소**: 매 판 새로운 유물/선택지로 타워를 조합해 나만의 빌드 완성

## 3. 핵심 시스템

### 3.1 두 개의 공간 (분리된 이중 확장 구조)

- **경영 공간**: 자원 생산, 주민 배치, 건물 건설, 영토 확장
- **전투 공간**: 타워 배치로 본진 수비 (병사 배치는 도입 여부 미확정 — §5.4 참고)
- 두 공간의 영토는 각각 독립적으로 관리되며 동시에 확장 가능

### 3.2 자원 흐름 (RESOURCE FLOW)

자원은 **나무 · 철 · 식량 · 마나석** 4종.

- **나무/철/식량**: 기본 자원 → 건물 건설, 건물 업그레이드, 타워 강화에 사용 (병사 시스템 도입 시 병사 훈련에도 사용). 획득 경로는 **(1) 생산 건물에 주민 배치, (2) 영토 확장 보상** 둘 다 가능.
- **마나석**: 영토 확장·전투 보상으로만 얻는 상위 자원 → 스킬 건물 업그레이드, 마나석 → 기본 자원 전환 건물 등에 사용

### 3.3 성장 루프 (GROWTH LOOP)

```
(최초 1회) 초기 자원 지급
  ↓
[낮] 타워 배치 + 주민 배치 → 낮 종료
  ↓
[밤] 전투 영토 확장 → 몬스터 스폰·이동 → 타워 공격 + 플레이어 스킬 개입
  ↓
웨이브 클리어 → 자원 정산 + 마나석 지급
  ↓
[낮] 경영 영토 확장(강제 1회) → 주민 배치 + 업그레이드
     (본진: 건물 최대 레벨 상승 / 스킬 건물: 능력 강화 / 마나석 → 기본 자원 전환)
     → 낮 종료
  ↓
(정해진 웨이브 수만큼 반복)
  ├─ 최종 웨이브 클리어 → 게임 승리
  └─ 웨이브 실패 (본진 HP = 0) → 즉시 게임 오버
```

※ 병사 시스템 도입 시 밤 페이즈에 병사 배치 단계가 추가됨 (도입 여부 미확정 — §5.4 참고)

### 3.4 승패 조건

- **게임 오버**: 전투 중 본진 HP가 0이 되면 해당 Run 종료
- **클리어 조건**: 모든 스테이지를 클리어하고 최종 보스를 처치하면 승리

## 4. 게임 루프 — 하루 2단계 사이클

```
낮(경영) → 밤(수비) → (다음날로 반복)
```

### 4.1 낮 (Morning Phase)

목표: 자원을 생산하고 건물·타워를 준비한다.

| 행동           | 공간 | 내용                                                                                                                      |
| -------------- | ---- | ------------------------------------------------------------------------------------------------------------------------- |
| 본진 체력 회복 | 경영 | 낮 시작 시 자동 회복                                                                                                      |
| 주민 배치      | 경영 | 보유한 주민 수만큼 생산 건물 또는 훈련장에 배치 (배치는 매일 초기화)                                                      |
| 건물 건설      | 경영 | 새 건물을 지어 할 수 있는 작업(생산·업그레이드 등)을 해금하는 시스템. 해금 대상 목록은 미정                               |
| 업그레이드     | 경영 | 본진 업그레이드(건물 최대 레벨 상승) / 스킬 건물 업그레이드(공격력·범위 상승, 쿨타임 감소) / 마나석 → 기본 자원 전환 건물 |
| 경영 영토 확장 | 경영 | 웨이브 클리어 후 인접 영토 하나를 선택해 확장, 영토마다 고유 효과 존재 (현재는 강제 1회, 이후 자원 소모형 전환 검토)      |
| 타워 배치      | 전투 | 확보한 자원으로 그리드에 타워 배치                                                                                        |

### 4.2 밤 (Evening Phase)

목표: 배치한 타워와 플레이어 스킬로 몬스터의 침공을 막아낸다.

| 행동           | 공간 | 내용                                                                       |
| -------------- | ---- | -------------------------------------------------------------------------- |
| 전투 영토 확장 | 전투 | 밤 시작 시 영토 1칸 자동 확장                                              |
| 몬스터 침공    | 전투 | 정해진 경로(웨이포인트)를 따라 본진으로 진격                               |
| 타워 공격      | 전투 | 사거리 내 몬스터를 자동 공격                                               |
| 플레이어 스킬  | 전투 | 범위를 지정해 발동, 몬스터에게 피해를 준다 (밤 동안 유일한 능동 개입 수단) |

### 4.3 밤 종료 — 결과 분기

- **웨이브 클리어**: 주민 배치로 얻은 자원 정산 + 마나석 지급 → 낮으로 전환
- **최종 웨이브(보스) 클리어**: 게임 승리
- **웨이브 실패** (본진 HP = 0): 즉시 게임오버

## 5. 세부 시스템

### 5.1 주민 시스템

- 영토 확장을 통해 주민 풀 증가
- 하루가 끝나면 주민 배치는 초기화됨
- 배치처: 자원 생산 건물(나무/철/식량) or 훈련장(병사 생성, 병사 시스템 도입 시)

### 5.2 건물 건설 & 타워 배치

- 경영 공간: 새 건물을 지어 할 수 있는 작업(생산·업그레이드 등)을 해금 — 해금 대상 목록은 미정
- 전투 공간: 확보한 자원으로 타워 건설
- 낮 동안 경영 공간은 건물을, 전투 공간은 타워를 배치하는 구조로 명확히 분리

### 5.3 경영 영토 확장

- 보유 영토(노란색) 기준 인접 영토(회색)만 선택 가능
- 웨이브 클리어 후 인접 영토 중 하나 선택 → 새로운 영토 확보 → 다음 확장 가능 영역 생성 (현재는 강제 1회, 이후 자원 소모형 전환 검토)
- 각 영토마다 고유 특수 효과 존재, 선택 시 효과 획득

### 5.4 병사 배치

도입 여부가 아직 확정되지 않은 시스템이다. 만약 도입한다면 아래와 같은 방식을 고려 중이다:

- 웨이포인트에만 배치 가능, 배치 후 이동 불가
- 역할: 타워로 막지 못한 몬스터 저지
- 사망 시 교회로 이동, 다음날 가용 주민 수 감소
- 주민을 자원 생산 vs 병사 훈련 중 어디에 배치할지가 매일의 전략적 선택

#### ⚠️ 검토 중 이슈 (현재 논의 사항)

- **문제 ①**: 병사 배치와 스킬 시스템 간 차별성 부족
- **문제 ②**: 병사만의 전략적 역할이 부족
- **검토 방향 ①**: 스킬 시스템과 병사 시스템 통합 검토
- **검토 방향 ②**: 주민 배치 전략성을 자원 생산 축으로 통합
- **목표**: 병사 시스템은 "주민을 자원 생산과 병사 운용 사이에서 고민하게 만드는 것"이 핵심 목적임을 재확인

### 5.5 스킬 시스템

- 스킬 종류는 최소화 — 초기에는 소수의 고정 스킬만 존재
- 사용 흐름: 스킬 버튼 클릭 → 범위 인디케이터가 마우스를 따라다님 → 원하는 위치를 클릭 → 그 범위에 스킬 발동
- 스킬 가짓수를 늘리기보다, 보상 시스템(§5.6)으로 기존 스킬에 특수 효과를 얹어 강화하는 방향

### 5.6 보상 시스템

- 매 웨이브가 아니라 **이벤트성**으로 지급 — 중간 보스 처치, 특정 웨이브 클리어 등 특정 조건에서 발생
- 보상 내용은 스킬 개수를 늘리는 게 아니라 **보유한 스킬에 특수 효과를 부여**하는 것
  - 예: 화염구 스킬 → 착탄 지점에 장판이 남아 지속 피해(도트 데미지)를 주는 효과 부여
- 3개의 특수 효과 카드 중 하나를 선택하는 방식 (로그라이크 빌드 형성의 핵심 축)
- 매 웨이브 클리어 시 지급되는 마나석(§4.3)과는 별도의 보상 트랙
