## 1. 회의해서 방향성을 새로 정해야 할 항목

> 결정이 없으면 착수 자체가 안 되는 것. 결론은 각 줄 뒤에 `→` 로 적는다.

- **자원 소비처** — 각 자원을 어디에 쓸지. 설탕은 지금 벌어도 살 것이 없다 
  - 생산 건물 업그레이드 쓰이는 자원 : 처음에는 각 건물에 해당하는 자원 -> 본진 업그레이드 이후 새로운 자원 추가(부가 재료 넣듯이 3가지 자원 넣기)
  - 캐슬 업그레이드: 4개 자원 사용 별사탕은 고정으로 얻어서 우리가 캐슬 업그레이드 타이밍을 조절할 수 있음
  - 주민 수 : 설탕
  - 타워: 공격 유형별로 세 가지 자원 적절히 분배해서 코스트 적용
- **전투 공간 개편**
  - 웨이브마다 몬스터 스폰되는 방식을 기존 순서 방식이 아닌 랜덤 스폰으로 변경(1순위)
  - 몬스터 1~2 종류(2순위)
  - 전투맵 꾸미기(3순위)
- **사냥꾼 타워** → 1레벨 기본타워로 사용하고 공격 시 공격력 증가 (웨이브 끝나면 스택 리셋)
- **램프업 타워** → 공격 시 공격력 + 공격속도 증가
- **소다 타워** → 스턴 로직 변경: 몬스터에 스턴 면역이 아닌 무한 스턴 방지를 타워 수치로 조정
- **몬스터 및 체력 바** → 몬스터랑 보스가 점점 강해지는데 그 비율을 체력바에 칸을 넣어서 표시
- **자원 보상 넣을지** → 일단은 다음주 밸런스 잡아보면서 넣을지 말지 결정
- **미니맵** → 전체 영토가 보이게 확대하기 - 건물 이동 패널을 미니맵에 배치 or 기존처럼 따로 패널에 배치 + 전투공간 이동 버튼 추가
-

## 2. 버그 / 고칠 것

> 동작이 **잘못된** 것. 담당 · 우선순위는 뒤에 적는다.

- 마지막에 고른 세이브 슬롯이 재실행 시 복원되지 않는다
- 물에 닿지 않은 오브젝트에 거품이 생긴다 (빌드 3부터)
- 카메라 이동 감도가 줌 배율을 따라가지 않는다
- 타워 아이콘 화풍 통일 기준 지금은 일관성이 없다
- 몬스터 웨이브 UI 정보 위치

## 3. 개선 사항

- 경영 공간 건물 시인성 — 건물 위 아이콘
- 자원 표기가 아이콘 단독이라 어느 자원인지 읽히지 않는다
- 주민을 들어 옮기는 조작에 연출이 없다
- 배속 버튼 하나로 줄이기 + 토글 방식으로 구현
- 웨이브 때 몬스터 나오는걸 한줄로 나오는거에서 풀에서 나오는걸로
- 몬스터 웨이브 정보에 몬스터가 얼마나 강해지는지 표시해주기
- 건물 업그레이드 및 자원 사용 시 Undo 기능 추가

## 5. 할 일 목록

> **팀 테스트 피드백**을 작업 단위로 합친 목록. `[피드백]` = 이번 테스트에서 나온 것, `[회의]` = §1 결정이 나야 착수 가능.

### UI · 시인성

- `[피드백]` **본진 HP 백보드가 밤에 안 보인다** — 야간 조명에서 배경이 묻혀 체력이 얼마 남았는지 · 얼마나 깎였는지 읽히지 않는다. 백보드 대비 확보 + 수치 표기 검토
- `[피드백]` **우측 자원(비스켓) · 초승달 아이콘이 좌우로 짜부러진다** — 원본 비율이 유지되지 않는다
- `[피드백]` **되돌리기 버튼이 있는지 인지하기 어렵다** — 타워 패널 옆이라 눈에 안 들어온다. 패널 위로 빼는 안 검토
- `[피드백]` **자원 부족 / 충분의 대비가 약하다** — 타워 버튼 배경만 어두워져서 설치 가능 여부가 구분되지 않는다. 아이콘 · 비용 텍스트까지 상태를 반영
- `[피드백]` **합성 패널의 타워 리스트가 Horizontal로 공간을 너무 먹는다** — 앞쪽 약한 타워만 보이고 뒤가 잘린다. 그리드 · 스크롤 · 정렬 재구성
- `[피드백]` **생산라인 `+` 버튼의 클릭 판정이 아이콘보다 왼쪽으로 치우쳐 있다**
- `[피드백]` **도감에서 등급(기본 · 레어 · 전설) 표기가 사라졌다** — 글자를 빼면서 등급을 알 수 있는 수단이 함께 없어졌다. 색 · 프레임 · 아이콘 중 무엇으로 되살릴지 정해서 복구
- `[피드백]` **화면 전환(낮 ↔ 밤) 버튼 크기 조정**
- `[피드백]` **미니맵을 어떻게 할지 결정 후 작업** `[회의]` — 삭제 / 경영 공간용으로 교체 + 카메라 이동 버튼 통합 / 버튼만 남기기
- 자원 표기가 아이콘 단독이라 어느 자원인지 읽히지 않는다 — 이름 · 툴팁 보강
- 경영 공간 건물 위 아이콘 표시
- 게임오버 · 팝업 UI 에셋 적용

### 로컬라이제이션

- `[피드백]` **영문 · 일본어에서 생산라인의 글자가 주민을 가린다** — 한국어 기준 폭으로 잡혀 있다. 3개 언어 모두에서 레이아웃 확인
- `[피드백]` **타워 패널의 글자가 씬을 리로드하지 않으면 언어 설정을 따라가지 않는다** — 즉시 갱신을 붙이거나, 글자를 없애기로 결정되면 삭제로 종결 `[회의]`
- `[피드백]` **설정 창의 "언어를 변경해주세요" 문구가 언어를 바꿔도 그대로다** — 로컬라이즈 키 누락
- 신규 UI(도감 · 웨이브 프리뷰 · 특수효과 패널)의 ko / en / ja 3개 언어 표기 전수 확인

### 전투 · 타일

- `[피드백]` **공격력 버프 타일과 사거리 버프 타일이 생김새가 같다** — 높이(고저)로만 구분돼 어느 버프인지 알 수 없다. 색 · 형태 · 아이콘으로 종류를 구분: 버프타일에 타워 올리면 버프 정보를 라벨로 띄워준다
- `[피드백]` **몬스터 애니메이션 재생 속도를 공격 속도 · 이동 속도에 맞춘다** — 지금은 수치와 모션이 따로 논다
- 몬스터 스폰을 불규칙하게 변경
- 기믹이 있는 몬스터 종류 1~2종 추가
- 타일 주변 맵 꾸미기

### 타워

- 사냥꾼 타워 · 소다 타워 로직 재작업
- 타워 아이콘 19종 재제작 — 화풍 통일 + 이름 규칙. **교체 후 19종 전수 확인**(스프라이트가 숫자 ID 참조라 재슬라이스 시 조용히 어긋난다)
- 타워 이펙트 적용

### 밸런스

- **타워 코스트 확정** — 자원 순환 · 몬스터 곡선이 모두 이 기준을 기다린다
- 자원 소비처 확정 후 수급량 · 건물 산출 · 업그레이드 비용 조정
- 몬스터 웨이브별 체력 · 수량을 자원 곡선에 맞춘다
- 스킬 · 보상 · 업그레이드 폭 조정
- 타워 합성 레시피 수정

### 시스템

- **튜토리얼 본체** — 안내 단계, 정본 씬 반영, 딤 · 강조 · 입력 차단, 다국어, 스킵 · 완료 기록
- **사운드 SFX** — 발사 · 명중 · 배치 · 합성 · 버튼 · 웨이브 클리어 + 스킬 착탄음 볼륨 편입
- **설정 패널** — 볼륨 슬라이더 3채널, 카메라 감도(줌 배율 추종 포함)
- **세이브 비동기 전환** — 마지막 슬롯 복원 버그를 함께 해결 (로딩 씬 도입 검토)
- 물 셰이더 거품 — 닿지 않은 오브젝트에 생기는 문제
- 주민을 들어 옮기는 조작 연출
