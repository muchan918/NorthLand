# 2팀 빌드 6 빌드 노트

- 팀명: 2팀 (유유아) · 빌드 번호: Build 6 · 빌드 일자: 2026-08-21
- Unity 6000.3.15f1 · Windows · `2팀 빌드 6.zip`
- 기준 기간: 8/14 (빌드 5) ~ 8/21 · 작성자: 김유찬

> **이번 빌드 한 줄** — 안 맞던 타워가 맞고, 조준 대상을 플레이어가 고르고, 타워 19종에 아이콘과 모델이 들어갔다.

---

## 신규

**타워 조준 정책** — 배치한 타워를 클릭해 정보 패널에서 **누구를 먼저 칠지** 고른다.

| 앞선 적 (기본) | 뒤처진 적 | 가까운 적 | 체력 높은 적 | 체력 낮은 적 |
| --- | --- | --- | --- | --- |
| 본진에 가장 가까운 | 가장 덜 진행한 | 타워에서 가장 가까운 | HP 최대 | HP 최소 |

- 기본값이 **"앞선 적"**이다. 이전(가장 가까운 적)과 다르므로 타워 19종의 거동이 전부 바뀌었다.

**웨이브 진행에 따른 타워 해금** — 타워 패널이 처음부터 다 열려 있지 않다.

| 1웨이브 | 3웨이브 | 4웨이브 | 5웨이브 | 6웨이브 |
| --- | --- | --- | --- | --- |
| 궁수 · 대포 · 독마법 | 가속의 탑 | 초코 폭포 | 소다 | 화염 지대 |

- 잠긴 슬롯도 자리를 지켜서 버튼 위치는 변하지 않는다. 해금 웨이브가 되면 자물쇠가 터지며 열린다.

**공격력 버프 타일 3종** — +10% / +20% / +30%. 같은 종류의 버프는 **합산**된다.

**합성 도감 패널** — 타워 19종의 아이콘 · 역할 · 스탯 · **합성 재료와 개수**를 열람한다. 등급별로 정렬 · 색 구분. 합성 패널과 같은 목록을 보므로 도감에 뜬 타워는 실제로 만들 수 있다.

**다음 웨이브 몬스터 프리뷰** — 밤으로 넘어가기 전에 **어떤 몬스터가 몇 마리 오는지** 본다. 보스는 빨간 `BOSS` 표기. 낮 · 밤 모두 현재 웨이브 번호가 뜬다.

**획득 특수효과 패널** — 지금까지 얻은 보상 5종(화상 · 폭탄 · 추가시전 · 전기장 · 처형)의 보유와 레벨을 아이콘으로 확인한다. 호버하면 이름과 레벨이 뜬다.

**건물 바로가기 패널** — 생산라인 위 버튼을 누르면 **카메라가 그 건물로 날아가고** 패널이 열린다.

## 🔧 변경

**타워 아이콘 19종 전부 적용** — 빈 테두리가 사라졌다. (화풍이 아직 제각각이다)

**타워 모델 · 애니메이션 4종 → 13종**

| 새로 적용된 타워 | 모습 |
| --- | --- |
| 소다 | **투석기** — 곡사로 포물선을 그린다 |
| 부메랑 · 사냥꾼 | **마시멜로** — 직접 던지고 재장전한다 |
| 소이탄 대포 | **박격포** |
| 화염 궁수 | 불타는 활 · 빨간 화살 |
| 개틀링 · 램프업 | 미니건 · 머신건 |
| 단일 · 멀티 인페르노 | 레이저 |

- **인페르노 빔이 3단계로 변한다** — 같은 적을 오래 조준할수록 굵어지고 하늘색 → 노랑 → 주적색으로 달아오른다. 램프가 얼마나 올랐는지 눈으로 읽힌다.
- 아직 임시 모델: **오라 4종(가속 · 독 · 초코 · 플레임필드) · 미사일 2종**

**화면 · 조작**

- 본진 체력바가 **마시멜로 이미지 6단계**로 변한다 (100 / 80 / 60 / 40 / 20 / 0%)
- 스킬 버튼이 **아이콘 + 원형 게이지**로 바뀌었다. 충전이 없으면 회색 + 남은 초, 있으면 충전 수
- **게임 중 ESC로 설정창을 열고 닫는다** (열리면 일시정지 · 게임 종료 후에는 안 열림)
- 게임 씬 UI 패널 크기 · 위치 정리, 도감 · 배속 · 합성 패널 아이콘 교체
- 마을 테두리의 **빈 땅을 채웠다** (캔디랜드 1차)
- 스타트맵과 전투맵의 **연결 지점을 다듬어** 빈틈 없이 이어진다
- **낮 종료 시 "타워를 배치하지 않았습니다" 경고를 삭제했다** — 아무것도 짓지 않는 것도 전략이다. 유휴 주민 경고만 남았다

## 🐛 해결 완료된 문제들(문제 - 해결)

- **타워가 아래쪽 길의 몬스터를 못 맞추던 문제** — 트리플 샷 · 부메랑이 제대로 때린다. 사거리 버프 타일에 올린 타워도 공중 유닛을 맞춘다
- **감전 · 폭탄이 공중 유닛(박쥐)에 닿지 않던 문제**
- **트리플 샷 타워가 대상을 매 프레임 바꿔 탄이 흩어지던 문제** — 화살 3발이 한 대상에게 들어간다
- **오라 타워 장판이 사거리 버프 타일에서 터무니없이 커지던 문제** (플레임필드가 화면 면적 10배까지 커졌다)
- **장판 이펙트가 실제 영향 범위보다 작게 보이던 문제** — 보이는 경계 = 실제 범위
- **도감과 합성 패널의 타워 목록이 어긋나던 문제** — 임시로 만든 도감 삭제
- 마법 연구소 강화 정보가 문장에 %로 보여져서 읽기 어렵다 — 마법 연구소 강화 정보가 **`데미지: 30 → 36` 실수치**로 표시된다 (기존 "40% 증가"는 환산이 불가능했다)
- 게임 오버 시 스킬 조준 표시가 결과 화면 뒤에 남던 문제 — 게임 오버 시 스킬을 취소 시킨다

## 🎮 플레이 흐름

**낮** — 자원 채집 · 주민 배치 → 건물 업그레이드 → 타워 배치 · 합성 → "다음"으로 밤 전환
**밤** — 타워 자동 공격 + 감전 스킬 시전 → 몬스터 전멸 시 클리어 → 별사탕 + 보상 3택1 → 다음 낮 (자동 저장)

- 총 **15웨이브** · 공중 8웨이브 · 중간보스 10웨이브 · 최종 보스 15웨이브
- 타이틀 → **세이브 슬롯 3개 중 선택** → 게임 시작 (슬롯을 안 고르면 시작되지 않음)
- 카메라 WASD · 우클릭 드래그 · 휠 줌 / 배속 x1 · x2 · x4 / 되돌리기(Undo)
- 타워 합성: Shift + 클릭 또는 좌클릭 드래그로 복수 선택 → 합성 버튼
- 감전: 스킬 버튼 → 전투 타일 클릭. **한 발 쏘면 조준이 풀려 버튼을 다시 눌러야 한다**
- 테스트용 **F4 디버그 패널** — 타워 무료 배치 · 스킬 레벨 조작 · 웨이브 점프 · 본진 무적 · 자원 조작

## 타워 19종(현재 임시 레시피와 등급이며 추후 변경 예정)

**직접 배치 7종**

| 타워 | 해금 | 역할 |
| --- | --- | --- |
| 궁수 타워 | 1 | 단일 대상 공격 |
| 대포 | 1 | 광역 — 착탄 지점 범위 피해 |
| 독마법 타워 | 1 | 독 장판 — 지속 피해 |
| 가속의 탑 | 3 | 아군 버프 — 범위 내 타워 공격속도 |
| 초코 폭포 타워 | 4 | 감속 장판 |
| 소다 타워 | 5 | 단일 + 짧은 스턴 (곡사) |
| 화염 지대 타워 | 6 | 화상 장판 |

**합성 전용 12종** — 재료는 **설치되어 있는 타워**여야 한다.

| 타워 | 재료 | 역할 |
| --- | --- | --- |
| 개틀링 | 궁수 ×2 | 빠른 연사 |
| 스나이퍼 | 궁수 + 대포 | 강력한 한 방 (**2x2 타일**) |
| 트리플 샷 | 궁수 ×3 | 부채꼴 3발 — 가까울수록 다 맞는다 |
| 부메랑 | 궁수 + 대포 ×2 | 관통 — 나갔다 되돌아온다 |
| 화염 궁수 | 궁수 + 화염 지대 | 단일 + 화상 |
| 소이탄 대포 | 대포 + 화염 지대 | 범위 피해 + 화염 구역 |
| 미사일 터렛 | 궁수 + 대포 + 화염 지대 | 착탄 지점에 화염 구역 |
| 2연발 미사일 터렛 | 미사일 터렛 ×2 | 2발 — 구역이 겹치면 중첩 |
| 멀티 인페르노 | 개틀링 ×2 + 독마법 | 여러 적을 레이저로 지진다 |
| 램프업 | 개틀링 + 가속의 탑 | 쏠수록 빨라진다 |
| 사냥꾼 | 대포 + 스나이퍼 | 처치할수록 강해진다 |
| 단일 인페르노 | 멀티 인페르노 + 스나이퍼 | 오래 조준할수록 급격히 강해진다 |

> 재료가 합성 전용인 타워는 **여러 단계**가 필요하다 — 단일 인페르노는 3단계다. 재료는 요구량보다 많이 골라도 필요한 개수만 소모된다. **합성 경로는 도감에서 확인한다.**

## 알려진 이슈

**플레이 중 마주치는 것**

- **조준 정책 「체력 높은/낮은 적」이 HP 절댓값으로 판정한다** — 체력바가 꽉 찬 적보다 반쯤 닳은 체력 많은 적을 먼저 때려서, 화면으로 읽는 것과 어긋난다
- **트리플 샷은 멀면 3발 중 1발만 맞는다** — 부채꼴이 벌어져 외곽 탄이 빗나간다
- 소다 타워를 여러 기 깔아도 **기절이 중첩되지 않는다** (의도한 동작)
- **타워 철거가 없다** — 되돌리기(Undo)가 유일한 회수 수단

**밸런스 미확정**

- **타워 코스트가 확정되지 않았다** — 자원 순환 · 몬스터 곡선이 모두 이 기준을 기다린다
- 소다 타워 수치, 미사일 2종, 성장형 3종(램프업 · 사냥꾼 · 단일 인페르노)은 **검증 전 잠정치**다
- 조준 기본값이 바뀌어 **기존 밸런스 실측은 다시 봐야 한다**
- **설탕(슈가 팜)은 쓸 곳이 없다** — 벌어도 살 것이 없다

**화면 · 소리**

- **볼륨 조절 슬라이더가 없다** / **BGM 크로스페이드 미동작** / 효과음은 낮·밤 스팅어와 주민 목소리뿐
- 보상 카드 이펙트 누락
- 물에 닿지 않은 오브젝트에 거품이 생긴다
- 카메라 이동 감도가 줌 배율을 따라가지 않는다
