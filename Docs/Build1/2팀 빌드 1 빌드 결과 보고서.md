- 빌드 번호: Build 1
- 테스트 일자:
- 테스트 환경

## 테스트 결과 요약

- 총 25개 항목 중 22개 정상 동작(O), 3개 미흡(x) — 낮/밤 전환, 영토 확장(경영/전투 공간), 몬스터 스폰·이동, 타워 공격~본진 피해~게임오버로 이어지는 핵심 루프는 전부 정상 동작 확인
- 미흡 항목 4건
  - 게임 시작 시 초기 자원이 지급되지 않음
  - 타워 배치 시 자원이 차감되지 않음(비용 검증 없이 배치 가능함)
  - "보스 처치" 클릭 시 웨이브 종료 시점까지 지연 분기하지 않고 즉시 처리됨(의도한 지연 판정 미동작)
  - "웨이브 성공" 클릭 시 몬스터 사망 처리 미구현

## 기능별 테스트 결과

### 씬 흐름

- [O] TitleScene → "게임 시작" 버튼 → GameScene 전환이 정상 동작한다

### 경영 공간 - 자원 / 주민 배치

- [x] 게임 시작 시 타워 하나를 배치할 수 있을 만큼의 초기 자원이 지급되어 있다
- [O] 낮 종료(End Day) 버튼을 눌러도 그 즉시 자원이 정산되지 않는다
- [O] 웨이브 성공 시에만 그 밤 동안 배치했던 주민 수 기준으로 자원이 정산되고 WaveCount가 1씩 증가한다

### 경영 공간 - 건물 정보

- [O] 건물에 호버하면 툴팁이 뜬다
- [O] 건물을 클릭하면 툴팁이 사라지고 우측 상단에 상세 설명 패널이 뜬다

### 경영 공간 - 영토 확장

- [O] 본진 주변 확장 가능 영토가 회색 노드로 표시된다
- [O] 회색 노드 선택 시 해당 노드가 노란색(보유)으로 바뀐다
- [O] 영토가 확장될 때마다 보유 노드에 인접한 새 회색 노드가 노출된다
- [O] 회색(확장 가능) 영토 노드를 호버하면 색이 바뀌고, 벗어나면 원래 회색으로 되돌아온다

### 낮/밤 전환

- [O] 낮/밤 전환 시 조명이 실제로 바뀐다
- [O] 밤이 되면 좌측 하단에 디버깅 전용 "웨이브 성공"/"웨이브 실패"/"보스 처치" 버튼 3개가 나타난다.
- [O] "웨이브 성공" - 다음 낮 전환, "웨이브 실패" - 게임 오버, "보스 처치" 게임 클리어 UI가 나온다.

### 전투 공간 - 영토 확장 / 몬스터 스폰·이동

- [O] 밤 전환 시 전투 공간 영토가 하나 확장된다
- [O] 확장된 영토의 End Point에서 몬스터가 SpawnInterval 간격으로 한 마리씩 순차 스폰된다
- [O] 낮에는 몬스터가 스폰되지 않는다
- [O] 스폰된 몬스터가 End Point에서 본진 방향으로 경로를 따라 이동한다

### 전투 공간 - 타워 배치

- [O] 타워를 전투 공간 그리드에 배치할 수 있고, 도로/용암 타일에는 배치되지 않는다
- [x] 배치 시 자원이 차감되고, 부족하면 배치되지 않는다

### 전투 시스템 - 공격 / 사망 / 본진 피해

- [O] 배치된 타워가 사거리 내 몬스터를 공격해 체력을 0으로 만들면 몬스터가 사라진다
- [O] 몬스터가 본진 사거리에 도달하면 본진을 공격하고, 본진 HP가 감소한다
- [O] 본진 HP가 0이 되면 GameOverUI가 실제로 표시된다

### 웨이브 종료 판정

- [O] 웨이브 실패 클릭 시에는 자원이 정산되지 않고 GameOverUI가 표시된다
- [x] 보스 처치 클릭 시 즉시 UI가 뜨지 않고, 웨이브 종료 시점에 GameClearUI 또는 평소 낮 전환으로 분기한다

### 게임오버 / 승리 UI

- [O] GameOverUI·GameClearUI의 "타이틀로"/"다시 시작" 버튼이 정상 동작한다

## 개선 사항

- 주민 배치가 낮/밤 전환마다 리셋되지 않고, 전날 배치 상태가 유지되도록 개선
- 경영 공간 영토 확장 시 확인 창(예: "이 영토를 확장하시겠습니까?") 띄우기
- 게임 오버 시 씬(전투 진행)이 정지되도록 개선
- 주민 배치 패널 구조 변경안
  - 예상 구조: `Wood(+3)  +- 40` / `Iron(+4)  +- ...` — 자원별로 주민 1인당 생산량(+3/+4 등)과 현재 배정 수를 +/- 로 조절하고, 그 옆에 보유량(예: 40)을 함께 표시
  - 목적: 정산된 자원과 보유한 자원을 별도로 더하는 과정 없이, 패널에서 바로 최종 보유량을 확인할 수 있게 하기 위함

## 발견된 버그 및 이슈

- 아처 타워 화살이 몬스터를 따라가는 구조라 몬스터 속도에 따른 어색함 발생
- 웨이브 수 이상 라운드 진행 시 낮이 전환되지 않음
- 타워 배치 시 자원 차감 미구현
- 몬스터 데이터 동기화 미구현
- 파란 몬스터는 Walk 애니메이션으로 동작하지 않고 이미 할당된(다른) 애니메이터가 재생되어 이동 애니메이션이 부자연스러움
