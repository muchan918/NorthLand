## 빌드 목표

- 낮밤 전환 시스템
- - 버튼 하나가 있고 그 버튼을 누르면 낮 종료가 된다
- - 밤으로 전환되면서 전투공간 영토가 하나 생기고 몬스터가 스폰된다

- 경영공간
- - 배치된 건물들의 정보를 볼 수 있다(마우스 갖다대면 정보가 뜸 -> 빌딩 데이터 설명을 가져온다)
- - 경영 공간에서 넓힐 영토를 미리 보여주고 일단 선택하면 그 영토가 확장되고 효과를 얻는 로그를 찍는다
- - 추가된 영토의 효과도 데이터로 관리한다
- - 영토는 선택 가능한 영토만 보여주며 hover 기능이 있다
- - 확보된 영토의 색을 변경시킨다

- 전투공간
- - 밤이 시작되면 영토가 하나 생성되고 end 포인트에 몬스터가 스폰된다
- - 몬스터는 웨이포인트를 따라 이동한다
- - 배치된 타워의 사정거리 안으로 몬스터가 들어오면 공격을 시작한다
- - hp가 0이된 몬스터는 사망한다
- - 몬스터가 본진에 도착하면 공격 시작한다

- 주민 배치 및 타워 배치
- - 주민은 UI 패널을 띄운 후 + - 버튼을 통해 주민을 배치한다
- - 주민 배치 완료 버튼 클릭 시 배치한 만큼의 자원을 즉시 정산 받는다
- - 타워는 낮에만 배치할 수 있고 타워 버튼 클릭 시 타워 프리팹이 마우스 포인터를 따라 다닌다
- - 타워는 전투 영영의 특정 타일에만 배치할 수 있다

- 기타
- - 카메라 이동 및 확대축소
- - 타워, 건물, 몬스터, 자원 데이터 구조 설계
- - 스트링 테이블 기반 언어 변경 적용 확인

- 빌드 테스트 목표
- - 경영 공간에서 영토 확장
- - 경영 공간에서 건물 정보 확인
- - 주민 배치 후 자원 획득
- - 밤 단계 진입 시 영토 생성 후 몬스터 스폰
- - 몬스터가 웨이포인트 따라 이동
- - 타워, 몬스터 공격 시스템 확인(몬스터가 죽는지, 본진이 파괴 되는지)

## 실행 방법

- 진입 씬: TitleScene → "게임 시작" 버튼 → GameScene(경영 공간)
- ## 조작법
  - 카메라: wasd 또는 드래그로 이동, 휠로 줌 인/아웃
  - 경영 공간에서 영토 확장: 좌측 확장 가능한(공개된) 영토 노드(Sphere)에 마우스를 올리면 하이라이트 → 좌클릭으로 선택/확장(하루 1회 제한) - 영토 확장을 하지 않으면 주민 배치가 불가하도록 임시 설계
  - 경영 공간에서 건물 정보 확인: 배치된 건물에 마우스를 갖다 대면(호버) 정보 툴팁이 뜨고, 클릭하면 정보 패널이 표시됨
  - 타워 배치 시스템: 하단에 버튼을 누르면 타워 고스트 프리팹 생성 → 땅 타일에만 배치할 수 있고 길, 용암 타일에는 타워 배치 불가
  - 주민 배치 후 자원 획득: 경영 패널의 생산 라인에서 `+`/`-` 버튼으로 주민 배정 → 좌측 하단 "낮 종료" 또는 우측 위 Next 버튼 클릭 시 밤으로 넘어감
  - 밤 단계 진입 시 전투 공간 영토 생성 후 몬스터 스폰: "낮 종료" 버튼 클릭 → 밤으로 전환되며 전투 공간 영토 생성 + 몬스터 자동 스폰됨
  - 몬스터는 자동으로 새로 생성된 영토의 end point에서 스폰됨
  - 몬스터 웨이포인트 이동 / 타워·몬스터 공격 확인: 밤 전환 후 별도 조작 없이 자동 진행 관찰(스폰 → 이동 → 사거리 진입 시 타워 공격 → 몬스터 사망 또는 본진 도착 시 공격)
  - 밤 단계 종료(임시 UI): 밤 화면의 "웨이브 성공"/"웨이브 실패"/"보스 처치" 버튼으로 다음 페이즈 전환(정식 웨이브 클리어 판정 연동 전 임시 트리거)
- ## 확인 포인트
  - 경영 공간 영토 확장 시 선택 가능한 영토만 노출되고 확장 후 색이 바뀌며 그 주변 선택 가능한 영토가 표시 되는지
  - 건물 호버/클릭 시 정보에 올바른 데이터가 표시되는지
  - 주민 배치 완료(낮 종료) 후 밤 웨이브를 클리어 하면 배정 수만큼 자원이 정산되는지
  - 밤 진입 시 영토가 생성되고 end 포인트에서 몬스터가 스폰되는지
  - 몬스터가 웨이포인트를 따라 정상 이동하는지
  - 타워 사거리 진입 시 공격이 시작되고 몬스터 HP 0에 사망하는지, 본진 도달 시 공격 및 게임오버 판정이 붙는지

## 알려진 이슈 / 제약사항

- 영토를 확장하지 않으면 주민 배치가 불가능하며, 확장 가능한 영토를 모두 소진하면 낮 진행이 막힐 수 있음 (WL-035)
- 영토 확장 시 효과(자원 보너스 등)는 아직 실제로 적용되지 않음 (WL-030)
- 임시 UI 버튼("웨이브 성공"/"웨이브 실패"/"보스 처치")으로 수동 트리거할 때 게임 흐름이 정확하지 않음 (WL-018)
- 몬스터가 타워 사거리 밖에서 성문을 두드리는 경우 "웨이브 성공"으로 자연 종료되지 않고 성문 파괴(게임오버)로만 끝날 수 있음 (WL-037)
- 몬스터 이동 속도가 EnemyAsset 데이터와 연결되지 않고 하드코딩된 고정값을 사용 중 (WL-036)
- 몬스터 사망/피격 애니메이션 상태(FSM)가 실제 전투 로직과 아직 연결되지 않아 시각적으로 즉시 사라짐 (WL-038)
