## 빌드 목표

- 낮밤 전환 시스템
- - 버튼 하나가 있고 그 버튼을 누르면 낮 종료가 된다
- - 밤으로 전환되면서 전투공간 영토가 하나 생기고 몬스터가 스폰된다

- 경영공간
- - 배치된 건물들의 정보를 볼 수 있다(마우스 갖다대면 정보가 뜸 -> 빌딩 데이터 설명을 가져온다)
- - 경영 공간에서 넓힐 영토를 미리 보여주고 일단 선택하면 그 영토가 확장되고 효과를 얻는 로그를 찍는다
- - 추가된 영토의 효과도 데이터로 관리한다
- - 영토는 선택 가능한 영토만 보여주며 hover 기능이 있다
- - 확보된 영토의 색을 변경시킨다

- 전투공간
- - 밤이 시작되면 영토가 하나 생성되고 end 포인트에 몬스터 스폰
- - 몬스터는 웨이포인트를 따라 이동
- - 배치된 타워의 사정거리 안으로 몬스터가 들어오면 공격을 시작
- - hp가 0이된 몬스터는 사망
- - 몬스터가 본진에 도착하면 공격 시작

- 주민 배치 및 타워 배치
- - 주민은 UI 패널을 띄운 후 + - 버튼을 통해 주민을 배치한다
- - 주민 배치 완료 버튼 클릭 시 배치한 만큼의 자원을 즉시 정산 받는다
- - 타워는 낮에만 배치할 수 있고 타워 버튼 클릭 시 타워 프리팹이 마우스 포인터를 따라 다닌다
- - 타워는 전투 영영의 특정 타일에만 배치할 수 있다

- 기타
- - 카메라 이동 및 확대축소
- - 타워, 건물, 몬스터, 자원 데이터 구조 설계
- - 스트링 테이블 기반 언어 변경 적용 확인

- 빌드 테스트 목표
- - 경영 공간에서 영토 확장
- - 경영 공간에서 건물 정보 확인
- - 주민 배치 후 자원 획득
- - 밤 단계 진입 시 영토 생성 후 몬스터 스폰
- - 몬스터가 웨이포인트 따라 이동
- - 타워, 몬스터 공격 시스템 확인(몬스터가 죽는지, 본진이 파괴 되는지)
