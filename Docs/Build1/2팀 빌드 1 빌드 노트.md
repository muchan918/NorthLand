## 빌드 목표

- 낮/밤 전환 시스템
  - 버튼 하나가 있고 그 버튼을 누르면 낮 종료가 된다
  - 밤으로 전환되면서 전투공간 영토가 하나 생기고 몬스터가 스폰된다

- 경영공간
  - 배치된 건물들의 정보를 볼 수 있다(마우스 갖다대면 정보가 뜸 → 빌딩 데이터 설명을 가져온다)
  - 경영 공간에서 넓힐 영토를 미리 보여주고 일단 선택하면 그 영토가 확장되고 효과를 얻는 로그를 찍는다
  - 추가된 영토의 효과도 데이터로 관리한다
  - 영토는 선택 가능한 영토만 보여주며 hover 기능이 있다
  - 확보된 영토의 색을 변경시킨다

- 전투공간
  - 밤이 시작되면 영토가 하나 생성되고 end 포인트에 몬스터가 스폰된다
  - 몬스터는 웨이포인트를 따라 이동한다
  - 배치된 타워의 사정거리 안으로 몬스터가 들어오면 공격을 시작한다
  - hp가 0이된 몬스터는 사망한다
  - 몬스터가 본진에 도착하면 공격 시작한다

- 주민 배치 및 타워 배치
  - 주민은 UI 패널을 띄운 후 +/- 버튼을 통해 주민을 배치한다
  - 주민 배치 완료 버튼 클릭 시 배치한 만큼의 자원을 즉시 정산 받는다
  - 타워는 낮에만 배치할 수 있고 타워 버튼 클릭 시 타워 프리팹이 마우스 포인터를 따라 다닌다
  - 타워는 전투 영역의 특정 타일에만 배치할 수 있다

- 기타
  - 카메라 이동 및 확대축소
  - 타워, 건물, 몬스터, 자원 데이터 구조 설계
  - 스트링 테이블 기반 언어 변경 적용 확인

## 목표 대비 구현 현황

| 분류           | 목표                                                                                 | 상태 |
| -------------- | ------------------------------------------------------------------------------------ | ---- |
| 낮/밤          | - 낮 종료 버튼<br>- 밤 전환 시 영토 생성+몬스터 스폰                                 | 완료 |
| 경영공간       | - 건물 정보 확인<br>- 영토 확장 노출/선택/색 변경                                    | 완료 |
| 전투공간       | - 영토 생성+스폰<br>- 웨이포인트 이동<br>- 사거리 공격<br>- 사망 처리<br>- 본진 공격 | 완료 |
| 주민/타워 배치 | - 주민 +/- 배치<br>- 낮에만·특정 타일에만 타워 배치                                  | 완료 |
| 기타           | - 카메라 이동/줌<br>- 데이터 구조 설계<br>- 언어 전환                                | 완료 |

목표 대비 달라진 부분은 다음과 같다. 경영공간의 영토 확장 효과는 데이터 구조만 있고 실제 적용은 아직 안 됐다(WL-030). 주민 배치 자원 정산은 "즉시"가 아니라 **웨이브 성공 시**로 확정됐고, 타워 배치 시 자원 차감은 아직 미구현이다.

**요약**: 낮/밤 전환 → 영토 확장 → 몬스터 스폰·이동 → 타워 공격·본진 피해·게임오버로 이어지는 핵심 루프는 전부 목표대로 확인됨. 미흡 4건(초기 자원 미지급, 타워 배치 자원 차감 미구현, "보스 처치" 지연 분기 미동작, "웨이브 성공" 시 몬스터 정리 미구현)

## 실행 방법

- 진입 씬: TitleScene → "게임 시작" 버튼 → GameScene(경영 공간)
- 카메라: wasd 또는 드래그로 이동, 휠로 줌 인/아웃
- 영토 확장: 좌측 확장 가능한 영토 노드(회색)에 호버 → 좌클릭으로 선택/확장(하루 1회) — 확장하지 않으면 주민 배치 불가
- 건물 정보: 배치된 건물에 호버 시 툴팁, 클릭 시 상세 패널
- 타워 배치: 하단 버튼 클릭 → 고스트 프리팹이 마우스를 따라다니고 땅 타일에만 배치 가능(길/용암 불가)
- 주민 배치: 경영 패널 생산 라인에서 `+`/`-`로 배정 → "낮 종료"/Next 클릭 시 밤 전환(주민 수 총합 5를 맞추지 않으면 낮 종료 처리 안됨)
- 밤 전환: "낮 종료" 클릭 → 전투 공간 영토 생성 + end point에서 몬스터 자동 스폰, 이후 이동·타워 공격·사망/본진 피해까지 자동 진행
- 밤 종료(임시): 밤 화면의 "웨이브 성공"/"웨이브 실패"/"보스 처치" 버튼으로 다음 페이즈 전환

## 알려진 이슈 / 제약사항

- 영토를 확장하지 않으면 주민 배치가 불가능하며, 확장 가능한 영토를 모두 소진하면 낮 진행이 막힐 수 있음 (WL-035)
- 영토 확장 시 효과(자원 보너스 등)는 아직 실제로 적용되지 않음 (WL-030)
- 임시 UI 버튼("웨이브 성공"/"웨이브 실패"/"보스 처치")으로 수동 트리거할 때 게임 흐름이 정확하지 않음 (WL-018)
- 몬스터가 타워 사거리 밖에서 성문을 두드리는 경우 "웨이브 성공"으로 자연 종료되지 않고 성문 파괴(게임오버)로만 끝날 수 있음 (WL-037)
- 몬스터 이동 속도가 EnemyAsset 데이터와 연결되지 않고 하드코딩된 고정값을 사용 중 (WL-036)
- 몬스터 사망/피격 애니메이션 상태(FSM)가 실제 전투 로직과 아직 연결되지 않아 시각적으로 즉시 사라짐 (WL-038)
